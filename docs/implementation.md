# 双网盘实现与验收进度

## 已接入的代码

- 公共文件模型使用 `RemoteReference` 区分百度路径与夸克 fid；任务固定 `AccountKey`、账号名称、远端目录及转存回执。
- `BaiduNetdisk`、`QuarkNetdisk` 实现轻量策略。`RoutedDownloadSource` 按上下文选择会话，两家共用下载引擎和全局资源上限。
- 分享转存先保存目录和提交意图，再提交并保存回执。写盘失败停止远端操作；重试优先查询已知回执，结果不明时保留目录并报错。
- 夸克跨层级部分选择按相对父目录分批转存，保留同名文件所在的各自目录；逐批保存目标 fid、意图、回执和完成结果。恢复只继续明确未提交的批次，已有回执查询原任务；旧单次回执继续兼容。
- 登录、退出和代理替换撤销旧客户端，停止旧准备任务；异步校验发布会话前复核版本，旧响应不覆盖新账号。
- 旧百度任务转换账号归属，下载 ID 和分片不变。升级任务 JSON 与下载上下文前分别保留备份；损坏记录不会当作新下载覆盖进度。
- 支持两家分享与账号内文件选择；网盘、分类和搜索共同筛选列表。列表操作只取可见任务，选中操作取可见交集，移除确认冻结目标与清理选择。
- 主窗口处理原生全选命令，只选当前可见任务。点击列表显式转移键盘焦点，搜索输入继续由文本框处理全选；筛选造成的选择收窄不会抢走搜索焦点。
- 设置分别保存两家转存目录、清理和连接数。实际下载共用一个闲置防休眠活动，退出、暂停及完成时释放。
- 剪贴板异步检测返回后检查窗口任务取消状态；关闭添加窗口或应用退出后不再启动分享读取或弹出添加窗口。
- 取消收尾中的下载继续占用全局并发名额；清理完成前保留下载 ID，避免旧取消操作删除同 ID 新任务的临时文件及进度。
- 移除任务返回前同步清除其下载快照和运行标记，不依赖事件流稍后消费 removed，避免残留进度及闲置防休眠活动。
- 底部状态栏汇总两家全部任务的已下载／总大小、速度及文件完成数，统计弹层显示进度和预计剩余时间；准备中的任务明确标注大小未确定。完成文件数沿用增量统计，进度刷新不扫描全部文件。
- 调整文件数或连接数预算时先保存并结束旧传输，再按最新预算排队；手动暂停保持不变。续传发现远端不支持 Range 时保留已有字节并提示重新添加，不静默截断重下。

## 验证命令

```sh
bash Scripts/test-packages.sh
bash Scripts/build-app.sh
".build/Ferry Plus.app/Contents/MacOS/Ferry Plus" --verify-drive-interfaces
".build/Ferry Plus.app/Contents/MacOS/Ferry Plus" --verify-drive-resume
```

接口验证复用应用钥匙串、客户端、适配器和正式下载引擎，任务状态使用独立验证目录；不会和正在运行的主窗口同时写同一份任务列表。自动选择限定目录范围内的小文件，验证结果只输出来源、数量、大小、校验值和脱敏错误，不输出凭据或签名 URL。

两个接口验证参数仅在 Debug 构建中可用，运行前退出主 App。有界续传验证最多检查八个目录，选择大于 2 MiB、不超过 64 MiB 的账号文件；两阶段各读取 1 MiB 真实数据，执行正式暂停、保存、新引擎恢复和继续。验证专用传输层拒绝无 Range、HTTP 200、范围不符和超长响应；下一片不发网，等待正式暂停。任务与 partial 保留在 `.build/verification-resume/`，不修改主列表或删除账号源文件。两家都通过才返回退出码 0；无合适样本明确报告未验证。

2026-10-24 有界续传实测：百度样本 18264195 字节，夸克样本 4126338 字节。两家均在首次暂停保存 1048576 字节，新引擎恢复后保持暂停与相同进度；继续请求从 1048576 开始，再次暂停保存 2097152 字节。每家的两次真实响应均为 HTTP 206，响应体各 2097152 字节。目录查找按同层优先，避免一条深路径用尽八次目录查询。进程退出码为 0，标准错误为空；重新打开主 App 后原有 7 个任务仍在。该结果证明有限分片的实际断点恢复，不代表大文件全量下载、自然链接过期或物理睡眠恢复已验收。
