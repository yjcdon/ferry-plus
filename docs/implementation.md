- 新增任务提示采用固定 40 点单行布局，长标题中间省略并保留悬停全文。真实复现的路径为“百度＋失败＋无结果搜索”下添加夸克任务；旧布局多次触发 AppKit Update Constraints 异常，单改 safe area 或搜索空态仍失败。最终布局重建 Release 后，同一路径重复通过；“查看任务”切来源、全部分类、清搜索并选中新任务，移除任务同步清除旧提示。
- 工具栏搜索用小型 NSSearchField 桥接，直接回写 MainView 唯一搜索状态，更新当前 Binding 并处理原生取消 action。修复动态添加提示后字段清空而列表仍按旧词过滤的问题；连续两轮来源／分类切换、输入及取消均通过。⌘F 仅作用于活动主窗口，文本 ⌘A 替换和 640 点宽搜索可用；固定 104 点宽度并明确提供原生高度，不再观察窗口几何修改搜索尺寸，也未加入轮询。

- 公共文件模型使用 `RemoteReference` 区分百度路径与夸克 fid；任务固定 `AccountKey`、账号名称、远端目录及转存回执。

- 分享转存先保存目录和提交意图，再提交并保存回执。写盘失败停止远端操作；重试优先查询已知回执，结果不明时保留目录并报错。
- 夸克跨层级部分选择按相对父目录分批转存，保留同名文件所在的各自目录；逐批保存目标 fid、意图、回执和完成结果。恢复只继续明确未提交的批次，已有回执查询原任务；旧单次回执继续兼容。
- 登录、退出和代理替换撤销旧客户端，停止旧准备任务；异步校验发布会话前复核版本，旧响应不覆盖新账号。
- 旧百度任务转换账号归属，下载 ID 和分片不变。升级任务 JSON 与下载上下文前分别保留备份；损坏记录不会当作新下载覆盖进度。
- 支持两家分享与账号内文件选择；网盘、分类和搜索共同筛选列表。列表操作只取可见任务，选中操作取可见交集，移除确认冻结目标与清理选择。

- 剪贴板异步检测返回后检查窗口任务取消状态；关闭添加窗口或应用退出后不再启动分享读取或弹出添加窗口。
- 剪贴板检测在异步网址判断前后核对版本，变化或取消不读取及缓存旧结果；弹窗前再次核对版本与开关。Release 界面验证：筛选夸克时复制百度公开链接仍填入百度和提取码；取消后两次切回不重复弹窗；已有夸克分享任务不自动再打开，手动添加可填入；关闭检测后新复制不弹、手动添加仍可读取。测试后检测恢复开启，未创建新下载任务。版本变化的异步竞态为源码修复，未宣称界面稳定复现；跨网盘同短码与提取码由既有套件新增回归验证。
- 文件树展开和重试使用视图任务，收起、换树及关闭窗口取消加载；节点以请求标识隔离迟到结果，旧请求不清除新请求的加载状态，缓存命中不恢复用户已取消的选择。
- 取消收尾中的下载继续占用全局并发名额；清理完成前保留下载 ID，避免旧取消操作删除同 ID 新任务的临时文件及进度。
- 移除任务返回前同步清除其下载快照和运行标记，不依赖事件流稍后消费 removed，避免残留进度及闲置防休眠活动。
- 移到废纸篓先合并每个引擎取消操作收尾后确认的完成路径，再读取最新文件列表，避免取消期间刚完成的文件被旧快照遗漏。受控时序回归在旧实现确实失败，修复后通过；覆盖刚完成的同名编号文件进入测试废纸篓、原同名用户文件保留及 partial 清除。
- 底部状态栏汇总两家全部任务的已下载／总大小、速度及文件完成数，统计弹层显示进度和预计剩余时间；准备中的任务明确标注大小未确定。完成文件数沿用增量统计，进度刷新不扫描全部文件。
- 调整文件数或连接数预算时先保存并结束旧传输，再按最新预算排队；手动暂停保持不变。续传发现远端不支持 Range 时保留已有字节并提示重新添加，不静默截断重下。
- 修改单家连接数同步已有请求，即使另一家维持共享最大值也重新收尾生效；排队、暂停、重启恢复及跨 actor 迟到的请求均使用最新来源配置。实际本地 HTTP 分片回归覆盖单家升降、快速降后升、收尾中新任务及暂停保留；两家任务路由通过现有协调器套件验证。

## 完成通知的验证入口

首次任务共享一个系统授权请求，完成通知等待该请求返回；拒绝或失败不影响下载。退出时取消授权任务但不等待系统提示，回调返回后复核取消状态；通知异步任务不持有应用模型。

Debug App 提供只读诊断：

```sh
".build/Ferry Plus.app/Contents/MacOS/Ferry Plus" --inspect-notifications
".build/Ferry Plus.app/Contents/MacOS/Ferry Plus" --inspect-notifications --notification-job <任务UUID> --notification-since <开始时间Unix秒> --notification-provider <baidu或quark>
```

未提供完整过滤条件时仅返回本应用的通知授权和显示设置，不读取旧通知。完整且有效的条件只匹配指定任务及开始时间之后的本应用通知，返回匹配数量、标题及网盘来源是否正确，不输出正文、文件名或其他应用通知；重复、未知或无效参数返回错误。该入口不启动任务队列，也不请求或修改系统授权。

2026-10-24 通过正常界面完成实际验收：系统设置原为本应用通知关闭，诊断返回 `denied`；在该状态下百度 5139288 字节分享下载完成，匹配通知数为 0，下载结果不受影响。随后仅临时开启本应用通知，诊断返回 `authorized`：App 隐藏期间完成的百度 5139288 字节任务、App 前台完成的夸克 69 字节任务，按各自 UUID 和开始时间匹配到的系统送达通知均为 1，标题及网盘来源校验均为 true。测试后已恢复本应用通知关闭，重新查询为 `denied`；没有修改全局或其他应用通知设置。

查询命中证明系统已送达并仍保留在通知中心，不代表横幅当时可见。首次尚未决定授权时的竞态已按调用顺序修复并审查，但未重置本机授权来重放首次系统提示。非法 UUID、非有限时间、未知参数分别返回 `invalid_arguments`、退出码 1；缺少完整过滤条件时只返回权限且没有匹配计数字段，退出码 0。各项标准错误均为空。
