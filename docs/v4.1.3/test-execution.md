## 本轮发现与修复

1. 首次混合上传中，祖先路径别名使扫描得到 folder/folder/nested.txt，父目录不存在导致子文件失败。修复为先校验源根，再用真实枚举根计算相对路径；新增祖先符号链接回归测试，修复前失败、修复后通过。双网盘文件夹上传已重新完成。
2. 指定文件夹解析失败时，原列表回调会回退当前目录；现已拒绝该投放，空白投放才使用当前目录。
3. 最终 Review 未发现阻断实现的问题；源文件权限在书签和任务保存后释放，选择器取消恢复 busy，临时投放诊断已移除并停止日志进程。
