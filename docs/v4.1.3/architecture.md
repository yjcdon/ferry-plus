# 4.1.3 技术方案：直接上传

## 目标与产品依据

依据本次已确认交互：用户在百度或夸克的目标目录点击上传，系统选择器可多选文件和文件夹，确认即入队；拖到列表空白处上传到当前目录，拖到文件夹上传到该文件夹。取消原上传确认页，保持当前页面，传输列表展示进度。同名默认保留两份。文件列表空白处及空目录右键可新建文件夹，移除工具栏的新建文件夹按钮。

本版本收录已经完成的图标调整：下载使用 arrow.down（向下箭头），上传使用 icloud.and.arrow.up（云朵向上箭头）。版本由 4.1.2 升为 4.1.3。

## 现状与技术决策

MainView 已接收 DirectoryContext（包含账号、客户端会话和准确目录）；NetdiskOutlineView 已按投放位置区分当前目录与文件夹。原 UploadConfirmationView 在 sheet 中再打开 NSOpenPanel，并重复扫描、等待用户提交。

保留现有表格拖放与 UploadCoordinator 入队、后台扫描、冲突处理、上传和内容校验。以主窗口持有的轻量上传入口替代确认页，不新增上传执行引擎。

## 数据、生命周期与异常

- 用户打开选择器时冻结 DirectoryContext，确认后核对同一账号和客户端会话；切换会话时提示重新选择上传位置。
- 选择器附着主窗口，主窗口持有 presenter；取消不创建任务。入队期间保持源文件 security-scoped 访问，书签创建完成后释放。
- URL 在入口校验为本地文件并按标准路径去重，入队固定使用 keepBoth（同名保留两份）。原任务保存的其他策略继续可恢复。
- 扫描由既有后台任务完成，问题进入任务失败状态。原页面的容量预估只供预检使用，本次移除这份预估；实际容量不足沿用网盘上传接口错误与任务重试机制，不承诺容量预留。
- 传输页等缺少明确目录的拖入仍保留已有待选目标流程；确定目标后直接入队。
- 确认弹窗、下载、删除、重命名和现有内容校验不受本次流程调整影响。

- 行内编辑按回车或离开字段提交，Esc 保留已创建目录的默认名称；错误保留输入并就近提示，提交期间禁止重复提交。编辑只绑定准确引用，切换目录结束编辑。
- 指定文件夹目标解析失败时拒绝投放；只有空白投放使用当前目录，避免目标悄悄变化。
- 目录扫描先校验根项目，再按真实文件系统根计算子路径，兼容 /tmp、/var 等祖先路径别名。

## 测试与 Review

执行 Release 构建、相关上传包测试；安装最新 4.1.3 并通过 computer-use 验证系统选择器、取消、双网盘上传及目录刷新、拖放目标与同名行为。记录实际覆盖与待测项，不以编译替代界面验收。最终检查窗口/任务生命周期、全部入口和旧引用，记录本地提交。

- 点击新建立即显示【创建中】；默认名基于完整目录快照选择。创建回执直接插入现有树并编辑，省去创建前后重复列目录和整树刷新；同名冲突由网盘返回，保留已有文件夹。

- 重命名成功直接显示列表中的新名称，不显示成功横幅；失败继续在名称输入处提示。

### 反馈收敛

- 重命名和移入回收站成功后由列表变化表达结果；保留删除前的对象和范围确认。
- 登录问题归属账号入口和账号设置，复用状态、登录及重试操作；传输页移除重复登录横幅。账号状态异常使用橙色标识。
- 任务执行失败沿用任务行、详情和重试入口。任务尚未建立、批量命令失败、文件清理遗留等问题显示在当前工作区，保留原因及可用操作，取消模态错误弹窗。
- 上传详情的云端定位和源文件定位错误显示在详情内，重试清除旧错误，错误提示不占用模态交互状态。
- 任务记录加载及转存目录清理问题继续留在传输列表，避免丢失尚需处理的事项。通用操作异常不再统一冠以【上传】。
- 前台传输结束仅更新任务状态；系统完成、失败或跳过通知仅在后台提醒，沿用系统通知权限。

### 上传详情的信息层级

- 使用者先判断任务结果，再定位失败文件并重试。摘要保留任务名、状态、已传／总量、网盘与账号；完成、失败及跳过数量合并显示，零失败和零跳过省略。
- 失败任务在摘要提供【重试失败项】，复用现有传输命令和启用条件。逐文件失败原因只在对应项展示，批次级且没有失败文件的问题保留在摘要。
- 文件项展示名称、状态及文件大小；文件夹由图标识别。文件内容一致等后台校验结果不另占行，后台校验、任务持久化及失败判定保持原逻辑。详情只按页读文件清单，移除为成功提示逐项读取校验记录的展示逻辑。
- 每项的云端／Finder 定位、重新选择源文件及复制错误放在该项操作菜单中，沿用准确对象和能力条件。已有备份定位及备份名称复制入口继续保留。
- 底栏合并为总数、按需翻页、刷新和任务操作；超过每页 100 项时才显示翻页控件。

- 网盘用户名仅在账号菜单、账号设置和登录相关界面展示；上传／下载详情、添加分享链接、任务恢复与清理失败提示仅标识网盘。内部账号 ID、任务绑定和凭据存储保持原契约。

### 工作区与详情统一精简

- 新任务不显示【已加入传输】横幅及倒计时。保留文件页位置；进入传输页时，只在当前筛选可见时选中新任务，不擅自改变网盘或方向。
- 下载详情采用紧凑摘要、来源位置、文件清单和底部操作；保留进度、速度、剩余时间、文件完成数量、创建时间、来源链接／路径、转存目录及下载位置，移除重复分组和卡片留白。
- 账号入口正常时只显示【账号与设置】，异常时显示受影响网盘状态。侧栏和系统菜单的百度状态、登录及退出共用控件，确认仍归属对应窗口。
- 文件页、上传详情和主工作区共用紧凑错误反馈；短信息按内容高度展示，长信息可查看全文。字段校验继续贴近输入框；无云端对象的文件不显示云端定位命令，处理中暂时不可用的动作仍防重复提交。
- 移除无读取方的校验刷新计数及通知钩子；记录保存、归档和任务归属检查保持不变。表头直接使用原生 NSTableHeaderView，排序与列宽处理继续交给 AppKit。
- 分享链接空态为【添加分享链接／支持百度网盘和夸克网盘】，输入提示【粘贴分享链接】；回车打开和提取码自动识别保持原功能。

- 分享链接输入框移除独立粘贴按钮，使用系统文本粘贴（⌘V／右键粘贴）；原有自动识别和提取码解析保留。

## 文件行多选

文件树沿用 NSOutlineView 的原生 ⇧ 连续选择及 ⌘ 不连续选择，蓝色行高亮与勾选框共用 FileTree.selection。工具栏、右键下载／删除及底部数量共用该选择集合；父目录已包含的子项按原规则去重。排序、展开和勾选引起的刷新按准确文件引用恢复有效选择；进入其他目录或收到显式定位请求时按新上下文聚焦。
