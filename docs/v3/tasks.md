# Ferry Plus 3.0 实施任务清单

状态：实施中。更新日期：2026-10-25。依据：[功能清单](features.md)、[架构设计](architecture.md)。分功能实现与验证见 [执行记录](implementation.md)；勾选仍以每项完整完成标准为准。

## 1. 执行规则

- 本文共 20 项任务，全部属于同一次 3.0 交付；编号稳定，按依赖推进。勾选表示该项自身完成标准已有证据，不代表全版交付。当前实现与缺口见执行记录。
- 先验证未决接口能力，再做正式协议、队列、校验及恢复，最后接入界面并验收。复用现有登录，不重做登录流程。
- 每项记录代码范围、命令／操作、结果、证据路径和未解决问题；实现与所列验证都完成后才勾选。
- 复用已有测试和临时验证入口，不新增测试类。纯文档不构建；进入实现后，变更模块编译并运行相关已有检查，正式 App 验收使用重新构建的应用实际操作。
- 所有写入验证使用专用样本与可确认归属的目录，清理移入本地废纸篓／网盘回收站，不永久清空。不得将 Cookie、签名 URL 或验证码写入证据。
- 无法验证某项功能时记录阻断和影响，不把接口“可能支持”记为通过，也不静默删减本版范围。
- 2026-10-24 用户明确要求大文件已上传约 800M 即可，不再等待全量传完。该轮两家多 GiB 云端传输已暂停并保留检查点，后续继续功能实施与短验证；不把部分上传写成完整大文件回读通过。V3-T17 的多 GiB 全量等待按此指示停止，其他一致性与资源要求继续执行。

## 2. 顺序和依赖

| 阶段 | 任务顺序 | 阶段结果 |
| --- | --- | --- |
| 能力与数据基础 | V3-T01 → V3-T02 → V3-T03 | 续传、覆盖等能力有结论；状态与源文件清单可持久化 |
| 协议和资源基础 | V3-T04、V3-T05、V3-T12 | 双网盘上传适配、资源预算基础设施及现有下载接入；上传和回读消费者分别在 V3-T06、V3-T08 接入 |
| 上传和校验闭环 | V3-T06 → V3-T07 → V3-T08 → V3-T09 | 实际上传、合并核对、完整回读、安全覆盖 |
| 恢复和下载校验 | V3-T10、V3-T11 | 上传各阶段恢复、下载校验与正确完成语义 |
| 界面与兼容 | V3-T13、V3-T14 → V3-T15 → V3-T16 | 拖动上传、统一任务操作、生命周期和升级 |
| 交付验收 | V3-T17 → V3-T18 → V3-T19 | 数据、实际 App、资源和 3.0 构建产物有证据 |

表格是阶段顺序，具体前置条件以各任务为准。全部任务完成前不能把 3.0 标为交付完成；推送和发布按届时明确指令执行。
