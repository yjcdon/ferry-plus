# Ferry Plus 3.0 实施任务清单

版本：3.0。本版界面与产物核对完成。更新日期：2026-10-25。依据：[功能清单](features.md)、[架构设计](architecture.md)。实施编号和既有证据继续保留，发布进度以第 2 节的本版发布步骤为准，不按历史任务勾选数计算。

## 1. 执行规则

- 保留 20 个稳定任务编号作为实施与证据索引。2026-10-25 用户明确：极端异常自动恢复、夸克安全覆盖延期；生命周期和最终资源专项取消。依赖只指本版职责，不等待延期能力，也不将延期／取消记为已验证。
- 本版保留双网盘基础上传下载／删除、正常续传、完整 SHA-256 和百度安全覆盖。复用现有登录，完成剩余界面测试、最终代码复核和产物核对后，按用户指示推送并发布 3.0；不再开展延期能力的探索性接口调查。
- 记录代码范围、命令／操作、结果、证据路径和已知问题。既有勾选保留其证据范围；跨本版与延期能力的条目分别注明状态，不用单一复选框掩盖两者差别。
- 复用已有测试和临时验证入口，不新增测试类。纯文档不构建；进入实现后，变更模块编译并运行相关已有检查，正式 App 验收使用重新构建的应用实际操作。
- 所有写入验证使用专用样本与可确认归属的目录，清理移入本地废纸篓／网盘回收站，不永久清空。不得将 Cookie、签名 URL 或验证码写入证据。
- 无法验证某项功能时记录阻断和影响，不把接口“可能支持”记为通过，也不静默删减本版范围。
- 2026-10-24 用户明确要求大文件已上传约 800M 即可，不再等待全量传完。该轮两家多 GiB 云端传输已暂停并保留检查点，后续继续功能实施与短验证；不把部分上传写成完整大文件回读通过。V3-T17 的多 GiB 全量等待按此指示停止，正常功能和内容一致性要求继续执行，最终资源专项按最新指示取消。
