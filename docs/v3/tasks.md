# Ferry Plus 3.0 实施任务清单

状态：实施中。日期：2026-10-24。依据：[功能清单](features.md)、[架构设计](architecture.md)。分功能实现与验证见 [执行记录](implementation.md)；勾选仍以每项完整完成标准为准。

## 1. 执行规则

- 本文共 20 项任务，全部属于同一次 3.0 交付；编号稳定，按依赖推进。勾选表示该项自身完成标准已有证据，不代表全版交付。当前实现与缺口见执行记录。
- 先验证未决接口能力，再做正式协议、队列、校验及恢复，最后接入界面并验收。复用现有登录，不重做登录流程。
- 每项记录代码范围、命令／操作、结果、证据路径和未解决问题；实现与所列验证都完成后才勾选。
- 复用已有测试和临时验证入口，不新增测试类。纯文档不构建；进入实现后，变更模块编译并运行相关已有检查，正式 App 验收使用重新构建的应用实际操作。
- 所有写入验证使用专用样本与可确认归属的目录，清理移入本地废纸篓／网盘回收站，不永久清空。不得将 Cookie、签名 URL 或验证码写入证据。
- 无法验证某项功能时记录阻断和影响，不把接口“可能支持”记为通过，也不静默删减本版范围。
- 2026-10-24 用户明确要求大文件已上传约 800M 即可，不再等待全量传完。该轮两家多 GiB 云端传输已暂停并保留检查点，后续继续功能实施与短验证；不把部分上传写成完整大文件回读通过。V3-T17 的多 GiB 全量等待按此指示停止，其他一致性与资源要求继续执行。

## 2. 顺序和依赖

| 阶段 | 任务顺序 | 阶段结果 |
| --- | --- | --- |
| 能力与数据基础 | V3-T01 → V3-T02 → V3-T03 | 续传、覆盖等能力有结论；状态与源文件清单可持久化 |
| 协议和资源基础 | V3-T04、V3-T05、V3-T12 | 双网盘上传适配、资源预算基础设施及现有下载接入；上传和回读消费者分别在 V3-T06、V3-T08 接入 |
| 上传和校验闭环 | V3-T06 → V3-T07 → V3-T08 → V3-T09 | 实际上传、合并核对、完整回读、安全覆盖 |
| 恢复和下载校验 | V3-T10、V3-T11 | 上传各阶段恢复、下载校验与正确完成语义 |
| 界面与兼容 | V3-T13、V3-T14 → V3-T15 → V3-T16 | 拖动上传、统一任务操作、生命周期和升级 |
| 交付验收 | V3-T17 → V3-T18 → V3-T19 | 数据、实际 App、资源和 3.0 构建产物有证据 |

表格是阶段顺序，具体前置条件以各任务为准。全部任务完成前不能把 3.0 标为交付完成；推送和发布按届时明确指令执行。

## 3. 任务明细

- [ ] **V3-T01 补齐双网盘上传能力证据**

  **依赖：** 无。**覆盖：** V3-F02、V3-F05、V3-F06、V3-F07、V3-F09、V3-F10、V3-F12、V3-F18、V3-F19。

  **工作与范围：** 基于现有会话验证零字节、空目录、秒传、分片状态查询、跨进程续传、过期行为、合并核对、取消和安全替换。核实文件摘要、版本、容量和大小限制语义。更新 `docs/upload-validation.md` 的直接对应部分，保留原通过证据。

  **完成标准：** 两家分别有能力矩阵与脱敏回执；对暂时不能自然触发的过期场景区分受控验证和真实证据。安全覆盖明确并发条件、旧版本恢复和最终对象身份；不可实现时报告阻断，不以其他行为冒充完成。

- [x] **V3-T02 建立上传状态、校验记录和公共命令契约**

  **依赖：** V3-T01。**覆盖：** V3-F04、V3-F08、V3-F10、V3-F14、V3-F15、V3-F20、V3-F24。

  **工作与范围：** FerryCore 增加上传批次／文件清单、会话、回执、提交意图、失败阶段、校验依据、结果和版本化存储；定义只读 TransferSnapshot 和带方向的任务 ID。明确各记录唯一写入方与原子写边界，凭据沿用 Keychain。

  **完成标准：** 记录可保存恢复；坏记录、未知版本和保存失败显式报告；上传和下载 ID 不碰撞；移除任务与保留校验记录可独立处理；没有另存一套运行状态的 UI 模型。

- [x] **V3-T03 实现源文件扫描、授权和稳定校验基准**

  **依赖：** V3-T02。**覆盖：** V3-F01、V3-F02、V3-F05、V3-F13、V3-F18、V3-F23。

  **工作与范围：** 文件／文件夹混选、bookmark、递归清单、重叠选择去重、空项目、名称与权限检查、流式 SHA-256 和协议摘要、分块指纹。实现源文件重定位与内容复核，扫描和哈希可暂停。

  **完成标准：** 中文、多层和空目录清单正确；隐藏文件规则明确；符号链接不越界跟随；同名同大小不同内容不误去重；源文件被修改时停止，不把混合版本送入上传。内存随缓冲预算而不是单文件大小增长。

- [ ] **V3-T04 接入百度正式上传适配**

  **依赖：** V3-T01、V3-T02、V3-T03。**覆盖：** V3-F03、V3-F04、V3-F05、V3-F06、V3-F07、V3-F11。

  **工作与范围：** BaiduKit 和 FerryCore 百度上传适配接入预创建、分片、回执 MD5、合并、结果查询、有效会话恢复和目录能力；不把临时探针直接作为正式业务入口。

  **完成标准：** 当前登录完成真实小文件与分片上传；正确区分秒传、分片成功、合并成功和未知结果；错误进入统一分类；无凭据日志或另一个登录存储。

- [ ] **V3-T05 接入夸克正式上传适配**

  **依赖：** V3-T01、V3-T02、V3-T03。**覆盖：** V3-F03、V3-F04、V3-F05、V3-F06、V3-F07、V3-F11。

  **工作与范围：** QuarkKit 和 FerryCore 夸克上传适配接入预上传、哈希协商、OSS 签名、分片、合并、finish、结果查询及有效会话恢复。服务端分片参数和签名语义保持在适配器内。

  **完成标准：** 当前登录完成真实小文件与分片上传；ETag 只用于对应协议，OSS 请求不携带网盘 Cookie；秒传、空间限制、签名失效与合并未知结果分类正确。

- [ ] **V3-T06 实现共享上传引擎和调度**

  **依赖：** V3-T03、V3-T04、V3-T05、V3-T12。**覆盖：** V3-F06、V3-F08、V3-F09、V3-F11、V3-F15、V3-F23。

  **工作与范围：** UploadEngine 有界分片读取、队列优先级、确认后检查点、单片重试、进度事件与阶段切换，并接入 V3-T12 的连接许可和上传速率预算；根据当前账号取得目的端适配器。暂停等待旧 worker 停止写状态，再允许继续。

  **完成标准：** 两家混合任务和优先执行正确；字节进度不因重试累加；取消／暂停收尾期间不超并发、不出现两代 worker 写同一记录；上传数据与预读指纹一致。

- [ ] **V3-T07 实现合并、建目录及取消结果核对**

  **依赖：** V3-T06。**覆盖：** V3-F02、V3-F03、V3-F10、V3-F11、V3-F14、V3-F15。

  **工作与范围：** 副作用前意图落盘、确认回执持久化、未知结果查询、精确产物归属、取消收尾。创建目录失败不能误把用户同名目录认作可删除自有目录。

  **完成标准：** 模拟响应丢失与提交后结束进程，恢复查询同一操作；不重复创建成功文件、不提前丢恢复记录；取消保留成功内容，只清理本任务暂存对象。

- [ ] **V3-T08 实现上传完整回读和校验记录**

  **依赖：** V3-T03、V3-T07、V3-T12。**覆盖：** V3-F07、V3-F09、V3-F18、V3-F20、V3-F23。

  **工作与范围：** IntegrityService 复用精确文件地址解析；提取 DownloadKit 范围读取与流式消费能力，按顺序计算完整 SHA-256；实现无完整落盘副本的回读、重试和结果保存，并接入 V3-T12 的连接许可和下载速率预算。

  **完成标准：** 两家实际上传及秒传产物与原始基准一致；故意改错期望摘要能失败。回读断网只重试校验；进程重启从当前文件首字节重算，不伪造可序列化哈希检查点；半段重试不重复进入摘要；零字节不生成非法 Range。

- [ ] **V3-T09 实现同名策略和安全覆盖发布**

  **依赖：** V3-T01、V3-T07、V3-T08。**覆盖：** V3-F05、V3-F12、V3-F14、V3-F16、V3-F18。

  **工作与范围：** 保留两份、跳过、批次策略、同名目录合并及类型冲突；覆盖通过独立暂存、回读验证、可恢复发布和最终对象确认完成。将暂存空间算入预检。

  **完成标准：** 两家分别证明替换具备并发保护且旧内容可恢复，不能以可恢复旧版本代替并发保护；原目标在执行期间变化不会被误覆盖；不使用先删后传；新对象身份改变时重新建立或验证校验关联。安全能力不足为发布阻断，不允许仅隐藏覆盖选项就勾选完成。

- [ ] **V3-T10 实现跨阶段恢复和部分失败重试**

  **依赖：** V3-T06、V3-T07、V3-T08、V3-T09。**覆盖：** V3-F04、V3-F09、V3-F10、V3-F11、V3-F14、V3-F15。

  **工作与范围：** 从准备、发送、合并、校验、发布阶段分别恢复；同一会话分片核对、会话过期处理、重新定位源文件、登录恢复、取消未决记录与成功／跳过／失败汇总。

  **完成标准：** 手动暂停重开仍暂停；其他任务按阶段恢复；已完成文件不重传；源变化不拼接；校验期间删去本地源仍可用保存摘要完成回读；合并／发布未决不会无条件重试。

- [ ] **V3-T11 补齐下载校验、清理门槛和清单导入导出**

  **依赖：** V3-T02、V3-T08。**覆盖：** V3-F19、V3-F20、V3-F24。

  **工作与范围：** 两家元信息到 DownloadRequest 的校验依据贯通，SHA-256／MD5 最终落盘检查、未验证结果、源版本变化、摘要输入和清单匹配、记录导出／清理。调整分享自动清理，不在校验失败或缺基准时清理源。

  **完成标准：** 自有上传再次下载匹配原 SHA-256；相同大小不同内容、错误摘要和冲突依据正确失败；无摘要明确未验证；未知来源的 ETag 不作 MD5；导入不按行号配对、不访问清单越界路径；旧任务不误标已校验。

- [x] **V3-T12 接入共享连接、限速和代理设置**

  **依赖：** V3-T02。**覆盖：** V3-F08、V3-F17、V3-F23。

  **工作与范围：** 在既有通用模块中提供资源许可和上传／下载速率预算，先接入现有下载引擎；扩展 FerrySettings，保留旧下载参数语义和代理配置。设计可取消的等待和固定许可获取顺序。上传消费者在 V3-T06 接入，回读消费者在 V3-T08 接入。

  **完成标准：** 预算与速率接口可通过已有验证入口核对等待、取消、许可释放和公平性；现有下载受限速及连接预算约束，低速持续传输不被短总时限误杀，改设置保留进度。此任务不等待尚未实现的上传／回读消费者；三类真实混合负载在 V3-T17 验收，取消后的缓存和 worker 收尾也计入资源测量。

  **验收证据：** 当前源码独立重编译并重跑 FIFO／取消／释放／限速／定时器、非 Range 有界流及 Range 校验通过，见 `.build/t12-current-validation/report.md`。既有配置／换会话用例直接核对暂停意图、原位移和缺失字节续传，本轮完整 307 项测试通过（`.build/v3-preflight-directory-recheck-tests.log`）。这项勾选不代表 T17 真实三类混合负载或 T19 整体资源验收通过。

- [ ] **V3-T13 实现上传窗口和按网盘拖动上传**

  **依赖：** V3-T03、V3-T04、V3-T05、V3-T09、V3-T10。**覆盖：** V3-F01、V3-F02、V3-F03、V3-F05、V3-F12、V3-F13、V3-F22。

  **工作与范围：** 原生文件选择、三个平铺的工具栏入口、可点击／拖入的文件选择区域、上传目标窗口、网盘 Tab、目录操作、确认清单、冲突选择及 Finder 拖入。主窗口单一网盘沿用选择；目录窗口沿用当前目录；全部网盘必须确定目标。

  **完成标准：** 两家选定后拖入文件／文件夹均无需重选网盘；确认展示账号和目录；未登录、放下前切换、确认前换号正确；仅拖入不自动写云端；下载筛选下创建上传后能定位任务，分享文本仍走下载。

- [ ] **V3-T14 实现统一列表、菜单和批量操作**

  **依赖：** V3-T10、V3-T11、V3-T12。**覆盖：** V3-F08、V3-F14、V3-F15、V3-F16、V3-F20、V3-F22。

  **工作与范围：** 全部传输／下载／上传切换，网盘／状态／搜索组合筛选；统一 TransferSelection 路由工具栏、菜单和快捷键；阶段进度、校验结果、部分失败、详情与结果定位。

  **完成标准：** 菜单、右键、快捷键均不操作隐藏任务；上传发送 100% 后显示校验阶段；无依据下载和全跳过批次不冒充已校验成功；移除记录不会删除本地源或已上传文件。

  **工作与范围：** 按批次通知，账号退出／换号、代理变更、正常退出检查点、关闭窗口、系统睡眠唤醒和防休眠释放。未决提交需要恢复记录。

  **完成标准：** 完成／部分失败通知准确；暂停后退出重开状态不变；一家退出另一家继续；空闲无持续进度轮询，防休眠许可正确释放。睡眠现场无法完成时记录未验收，不能用普通暂停代替。

- [ ] **V3-T16 完成 2.0 升级和格式兼容**

  **完成标准：** 使用含已完成、暂停和进行中任务的 2.0 数据副本升级，账号不丢、原位移可续传；未知版本保留原文件并提示；移除新上传记录不损伤旧下载记录。

- [ ] **V3-T17 双网盘数据与恢复验收**

  **依赖：** V3-T09、V3-T10、V3-T11、V3-T12、V3-T16。**覆盖：** V3-F02、V3-F04～V3-F20、V3-F24。

  **工作与范围：** 两家各跑零字节、4 KiB、4 MiB、4 MiB+1、实际分片边界、多层空目录和多 GiB 样本；实际上传、完整回读、正式下载比对；验证秒传、断网、中断恢复、同大小内容变化、三种冲突策略、并发外部修改与取消。双网盘上传、下载、回读混合负载需验证总连接／速率预算、公平性及无死锁。

  **完成标准：** 有原始摘要、回读摘要、最终本地摘要及字节长度证据；必要时用系统独立计算复核。记录受控故障与真实服务结果的差别，所有功能对应已有验证结果；清理只针对测试对象。不重复已通过且未受改动影响的大文件传输。
