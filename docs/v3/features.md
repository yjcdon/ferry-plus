# Ferry Plus 3.0 功能清单

状态：实施与验收中。更新日期：2026-10-25。本文保留完整交付要求；完成状态以 [任务清单](tasks.md) 和 [执行记录](implementation.md) 为准。

## 1. 目标与范围

在 2.0 双网盘下载能力上增加百度、夸克的本地文件上传，并让上传、下载结果具有明确、可复核的内容校验依据。继续使用原生 SwiftUI、macOS 14 及以上、Apple Silicon，复用现有登录，交付独立 App。

本版覆盖手动文件／文件夹上传、传输管理、恢复、冲突处理和内容校验。以下功能属于同一次 3.0 交付，任务顺序不代表拆成后续版本。保留 [2.0 功能](../features.md)，发生调整时以本文的明确规则为准。

当前已接入双网盘正式上传、分片队列、有效会话续传、完整回读、下载校验及上传界面，并完成两家部分实际 App 验收。安全覆盖、部分未决提交／过期会话恢复和完整界面、生命周期及资源交付验收仍未完成，不据已有通过项宣称 3.0 已交付。最初的协议可行性证据继续保留在 [上传验证](../upload-validation.md)，后续实现与证据见 [执行记录](implementation.md)。

## 2. 产品方法与流程

| 方法 | 解决的问题 | 支撑功能 |
| --- | --- | --- |
| 复用账号和目录上下文 | 减少网盘选择及重复登录 | 添加上传、拖放、目标目录、账号绑定 |
| 统一传输管理，按网盘执行协议 | 两家操作一致且能恢复中断 | 分片、队列、暂停、重试、批量操作 |
| 原文件建立校验基准，完成后比对 | 区分接口成功与内容一致 | 上传回读、下载校验、校验记录 |
| 显式处理冲突和不确定结果 | 避免覆盖旧文件或重复提交 | 同名策略、合并核对、部分失败 |

普通上传：选择／拖入文件 → 确认账号与目标目录 → 检查、扫描并建立校验基准 → 分片上传或服务端确认秒传 → 合并结果核对 → 完整回读校验 → 完成。

覆盖上传：确认覆盖对象 → 上传为本任务独立暂存文件 → 完整回读校验 → 安全替换目标 → 核对最终文件身份与内容关联 → 完成。

恢复：读取任务 → 核对账号、源文件、服务端会话与已有结果 → 从未完成阶段继续。已经上传完成而校验中断，只恢复校验。

## 3. 完整功能清单

| 编号 | 功能 | 交付行为 |
| --- | --- | --- |
| V3-F01 | 文件选择与拖动上传 | 支持单文件、多文件、文件与文件夹混选；支持 Finder 拖入。选中百度／夸克后直接沿用该网盘，不重复选择，具体规则见第 4 节。 |
| V3-F02 | 文件夹与目录结构 | 递归扫描、保留相对层级、支持空目录和零字节文件；汇总文件数与大小。扫描取消不创建远端内容。无法读取的项目逐项提示，不冒充完整成功。 |
| V3-F03 | 上传目标 | 双网盘 Tab、根目录与子目录浏览、返回、刷新、新建文件夹；显示账号和完整目标路径；最近目录按账号分别记忆，使用前核对仍存在。 |
| V3-F04 | 账号复用与归属 | 每家一个账号，两家同时登录；上传任务固定绑定网盘与账号。换号、退出只影响对应任务，原任务不能自动转给新账号。 |
| V3-F05 | 上传前检查 | 检查读取权限、文件身份、目标目录、名称限制、可获取的剩余容量及单文件上限。容量未知明确显示未知；最终以服务端结果为准。覆盖暂存也计入所需空间。 |
| V3-F06 | 小文件与分片上传 | 自动按协议规划分片，有限并发；逐片记录确认回执，失败片独立重试，完成后合并；不把进度到 100% 当成整体成功。 |
| V3-F07 | 秒传 | 接入服务端正式返回的秒传结果；随机新内容走实际上传。秒传同样经过云端文件身份核对和完整回读校验。 |
| V3-F08 | 统一队列与优先级 | 两家上传与下载同时管理，支持排队和优先执行；优先级调整下一批调度顺序，不丢弃已传字节。 |
| V3-F09 | 暂停与继续 | 上传分片、文件扫描／哈希和回读校验支持暂停；已确认进度保留。合并、替换等远端操作只能停止后续步骤并核对结果，不宣称远端操作已暂停。 |
| V3-F10 | 持久化与重启恢复 | 保存文件清单、账号、目录、分片及阶段回执。正常退出、异常结束后可恢复；手动暂停保持暂停，已完成文件不重复上传。 |
| V3-F11 | 重试与部分失败 | 断网恢复、限流退避、签名刷新；仅重试失败文件或失败阶段。空间不足、源文件变化、账号失效需处理原因后继续。明确展示成功、失败和跳过数量。 |
| V3-F12 | 同名冲突 | 默认保留两份，可选跳过、覆盖，支持应用于本批次；同名目录合并，文件逐项决策。覆盖先验证新内容，再替换旧内容，详见第 6 节。 |
| V3-F13 | 重复任务识别 | 同账号、准确目标目录、相对名称及目录结构、完整源内容均一致且已有活动任务时，提醒并可定位原任务；不同本地位置的同内容同名文件也可识别。仅同名同大小不能判重；有意以不同名称上传相同内容不合并。用户可明确选择仍然上传，不静默跳过。 |
| V3-F14 | 批量操作与取消 | 暂停、继续、重试、取消、移除记录，范围由当前筛选／选中项确定。取消核对在途提交；已成功云端文件保留，移除记录不删除本地原件和已上传文件。 |
| V3-F15 | 进度与状态 | 展示准备、排队、上传、合并、校验、完成及失败，支持文件级明细。速度与剩余时间按当前阶段显示；网络重传不重复增加逻辑完成字节。 |
| V3-F16 | 结果操作 | 打开云端所在目录、Finder 定位源文件、查看错误与校验依据；源文件不存在时给出实际路径及原因。 |
| V3-F17 | 网络与传输设置 | 复用代理；增加上传文件并发、上传分片并发、上传／下载总速率上限。校验回读计入下载速率和连接预算，设置变化不清空进度。 |
| V3-F18 | 上传内容校验 | 建立原文件 SHA-256，分片上传和合并完成后完整回读云端内容比对；默认执行，不在失败时降级为“已校验”。网络中断后重试校验，不重复上传。 |
| V3-F19 | 下载内容校验 | 优先使用可关联的原始 SHA-256，其次使用语义已确认的远端完整文件摘要，或用户提供的校验值；核对最终落盘文件。缺少基准明确标为未验证。 |
| V3-F20 | 校验记录与导入导出 | 保存算法、基准来源、文件身份、大小、结果及时间；支持输入或导入 SHA-256／MD5、导出校验清单。移除任务默认保留可用于后续下载的校验记录，可单独清理。 |
| V3-F21 | 完成通知与生命周期 | 按批次通知完成／部分失败；活跃传输避免闲置睡眠，暂停或结束释放资源；关闭窗口不丢任务，退出保存状态。 |

## 4. 拖动上传与界面范围

| 拖入位置／上下文 | 行为 |
| --- | --- |
| 主窗口已选百度或夸克 | 使用当前网盘与账号，显示文件清单和上传目标确认；不再次要求选择网盘。优先带入该账号最近且仍有效的目录，没有则在确认窗口选目录。 |
| 网盘目录窗口已经选好网盘和目录 | 使用当前 Tab 的账号及当前浏览目录；拖入后确认栏显示“上传到：网盘／完整路径”。 |
| 主窗口为全部网盘 | 先明确目标网盘，再确认目录；不能静默选择百度或按文件类型猜测网盘。 |
| 主窗口处于下载方向筛选 | 文件拖入仍可创建上传；创建后定位对应上传任务，其他下载继续。 |
| 对应网盘未登录 | 保留待选文件，完成该网盘登录后核对目标和账号，再由用户确认上传。 |
| 拖入期间切换网盘／账号 | 以实际放下时的上下文创建待确认清单；确认前账号变化则重新确认，不能静默改投其他账号。 |

只把本地文件 URL 识别为文件上传；分享链接文本继续走原有下载入口。重复拖入同一文件与父目录时去除重叠选区，保留相对层级。拖入仅准备任务，显示账号、目录和冲突策略后点击上传才写入云端。

工具栏、菜单栏、右键及快捷键遵循同一个范围：网盘 × 传输方向 × 状态 × 搜索。选中项操作只处理可见已选项；未选中时的列表级操作只处理当前可见任务。发起操作时固定任务 ID，隐藏任务不受影响。底部全局统计标明“全部传输”，与当前列表数量区分。

## 5. 内容一致性规则

### 5.1 校验依据

| 文件来源 | 可用依据 | 允许的结果描述 |
| --- | --- | --- |
| 本次上传、服务端秒传 | 上传前原始 SHA-256，与完整回读比较 | 已校验完成；详情说明与本地原始内容一致 |
| 此前由 Ferry Plus 上传的同一远端文件版本 | 保存的原始 SHA-256 | 与原上传内容一致 |
| 其他云端／分享文件 | 语义确认的完整文件摘要，或用户提供的原始校验值 | 与指定依据一致，并显示算法及来源 |
| 没有可信依据 | 大小、Range、文件身份等结构检查 | 已下载，未验证源文件内容 |

文件大小相同、HTTP 成功、ETag、分片回执、本地单独计算的哈希都不能替代完整内容比对。MD5 结果按 MD5 展示，不描述为 SHA-256 级别的验证；网盘返回字段名相同也必须核实其语义。

校验基准记录文件身份及版本线索。远端变化时不沿用错误版本；无可靠版本标识时保留“原上传版本”这一依据并在结果中明示，必须实际比对，不能凭文件 ID 或名称复用历史通过状态。

### 5.2 完成、未验证和失败

- 上传只有合并确认、完整回读一致及必要的覆盖发布完成，才进入已完成。
- 下载有基准时，临时文件通过最终落盘校验后成为正式文件；比对失败停在失败，保留临时文件和原因。
- 下载无基准时，通过长度、范围和身份检查后可以生成正式文件并归入已完成，但整行和通知必须带“未验证”标识，不能展示“已校验”。可后补基准再验证。
- 批次有失败项显示部分失败；全部跳过显示已跳过，不发送上传成功通知；成功加跳过显示各自数量。
- 分享转存内容只在所需校验通过后自动清理；缺少校验依据或校验失败时保留，用户可通过明确的清理操作移入网盘回收站。

上传前与发送各分片时核对同一文件版本；源文件变化停止该文件并提示按新版本重新开始。完整回读默认额外消耗约一份文件大小的下载流量；失败重试可能更多。读取流直接参与哈希，不落盘完整副本。进程重启后允许当前未完成文件从头回读校验，已上传内容不重新发送。

## 6. 冲突、恢复与文件边界

- **安全覆盖：** 新文件以独立远端身份暂存，完整校验后再替换。替换必须保护外部并发更新，同时保留可恢复的旧版本；只做事前查询或保留备份不能代替并发保护。若接口无法满足此顺序或不能排除误覆盖，停止该项，保留旧文件及已校验的新文件并说明原因；不能先删旧文件。两家安全覆盖均是发布前验证项，不能以保留两份冒充覆盖验收通过。
- **不确定结果：** 合并、建目录、替换请求超时后先查询已保存回执和对象身份。无法确定时等待核对，不自动重复提交。仅名称、大小相同不足以认定是本任务产物。
- **续传：** 仅复用有效会话内服务端确认的分片；过期后重新创建上传会话，按接口实际能力决定能否复用分片，不承诺永久续传。
- **取消与移除：** 在途合并／替换需要核对后才能终结；成功文件保留。只清理确认为本任务所有的暂存对象及未完成会话；不清空回收站，不递归删除用户选择的目标目录。
- **目录及 Mac 文件：** 保留普通文件字节和目录结构；符号链接不自动跟随，逐项提示；包文件按目录处理并在添加时说明。文件权限、扩展属性、资源叉不属于普通网盘字节传输的保真范围。隐藏文件默认纳入所选目录，避免静默遗漏。
- **文件重新定位：** 移动后允许重新选择源文件，重新计算内容基准确认一致才能续传；iCloud 等尚未落地或当前不可读的文件提示先取得本地内容。

## 7. 验收与依赖

| 维度 | 完成标准 |
| --- | --- |
| 数据 | 两家分别覆盖零字节、4 KiB、4 MiB、4 MiB+1、实际分片边界前后及至少一个多 GiB 文件；完整上传回读与再次正式下载均匹配原始 SHA-256 |
| 目录 | 混合选择、多层目录、空目录、中文名称、重叠选择；无法处理项目有明确清单 |
| 恢复 | 暂停继续、重开、断网、签名更新、会话失效、合并响应丢失、校验中断；不重复成功文件、不混用源版本 |
| 冲突 | 保留两份、跳过、覆盖、同名目录合并；覆盖失败或外部修改时原文件可恢复 |
| 拖动与界面 | 百度／夸克已选后拖入文件和文件夹均沿用选择；目录窗口沿用当前目录；全部网盘、未登录和换号边界正确 |
| 校验语义 | 相同大小不同内容必须被检测；无基准不冒充已校验；失败不触发自动源清理 |
| 隔离 | 双网盘上传下载同时运行，批量命令只作用于当前范围，退出一家不影响另一家 |
| 交付 | 2.0 数据可升级；Release App 资源占用实测、签名与 ZIP 一致；实际 UI 验收通过 |

上传、下载速度及文件大小上限受账号权益和服务端限制。已有小样本证据不能替代大文件、续传、秒传及覆盖验收。具体依赖和能力缺口见 [架构设计](architecture.md)，实施及验证次序见 [任务清单](tasks.md)。
