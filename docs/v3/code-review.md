## 保留的边界和缺口

- 百度路径写入接口不能原子绑定目录 ID。本次检查拒绝已经变化的目录，查询与写请求间仍有并发窗口。
- 部分预创建、建目录、百度合并回执丢失或过期会话场景缺少准确查询依据，可能保持“结果待核对”；当前不会据同名文件、404 或空结果盲目重发。不能宣称全部异常自动恢复。
- 夸克安全覆盖暂不支持；保留两份、跳过、基础上传与删除可用，不继续打开探索性授权窗口。
- 原生工具栏 AX 动作查询的持续分配已在纯 AppKit 最小程序复现，当前没有有效应用修复，不能记为已解决；不因取消资源专项而抹除已有事实。
- 用户取消生命周期与最终资源专项，未执行的场景不写为通过。未知提交恢复缺口仍保留在任务清单，当前候选不等于完整原方案全部完成。
