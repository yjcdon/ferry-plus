## 源文件扫描与内容基准

`FerryCore/UploadSource.swift` 已提供流式源文件扫描、权限书签、文件身份、完整 SHA-256／MD5／SHA-1、首 256 KiB MD5 及指定分块指纹。内容读取缓冲为 1 MiB；扫描通过事件逐项交付，包含隐藏文件和空目录，重叠选择去重，符号链接与不可读项目有独立问题记录。

源文件读取前后核对设备、inode、大小和纳秒修改／状态变更时间；文件描述符禁止跟随最终符号链接。每个读取块支持暂停检查点和取消。重新定位文件时重新读取完整摘要，不仅比较名称或大小。

验证证据：`.build/source-validation/` 的独立临时程序完成标准 `abc` 摘要、零字节摘要、非整块末片、隐藏／空目录、重叠选择、符号链接、读取期间修改与取消传播。主代理在 `.build/source-recheck/` 重新运行同一已编译验证程序，结果通过。没有新增测试类，没有操作原始用户文件。

统一 `swift build --package-path Packages/FerryKit --configuration release --jobs 4` 已通过，当前工具链默认 SDK 为 macOS 27.0。本次只证明包编译及上述本地行为，尚未接入上传界面，不将其记为完整 V3-T03 验收通过。

## 上传状态与独立校验记录

`UploadRecords.swift` 和 `UploadStore.swift` 已提供批次、分文件检查点、上传会话、分片确认、提交意图与校验依据模型。扫描先逐文件暂存，再原子发布批次清单；列表读取批次，不同时装入所有文件的分片。账号和已发布成员关系以落盘清单为准，校验记录独立保存，移除任务记录不会删除本地原件或云端文件。

实际验证发现并修复：没有上传会话的文件记录，原先可能接受另一账号的同 ID 批次快照。现在加载、保存以及向已发布批次暂存文件时，均核对真正清单的账号；首次批次发布使用独立内部读取路径，避免尚无清单时的递归或误拒绝。

主代理重新构建包后，直接链接实际 `libFerryCore.a` 执行独立程序，18 项检查全部通过：暂存／发布／恢复、跨账号读写拒绝、摘要结果一致性、未知版本保留、损坏 JSON、写失败传播，以及移除任务后保留校验记录。证据：`.build/upload-record-validation/result-package.txt`。验证只使用专用临时目录，未触碰真实应用状态，没有新增测试类。

## 夸克正式上传协议基础

`QuarkClient+Upload.swift` 已接入预上传、哈希协商、单片认证／发送、OSS 合并和网盘 finish，沿用现有客户端 Cookie 更新与撤销机制。普通会话保存准确的预分配文件 FID、任务和存储对象身份；授权上下文提供独立 Keychain 编解码接口，短期 auth_key 仅用于内存请求。OSS 请求不发送网盘 Cookie。

真实验证修正了两项接口契约：服务端提供 `http://pds.quark.cn` 作为存储定位，客户端接受该定位但实际上传构造 HTTPS；预上传时间必须是整数毫秒，浮点毫秒实测触发 HTTP 500。完成后的目录可见性存在延迟，验证按预分配 FID 有界核对，不按同名同大小认领对象。

## 下载端 SHA-256 落盘校验

DownloadRequest 新增可选 `expectedSHA256`，保留旧 MD5 参数及旧格式解码兼容。有两种摘要时一次流式读取临时文件同时核对；摘要不符时保留临时内容，不移动为正式文件、不保存完成回执。队列加入与恢复边界校验期望摘要格式，错误值不会先触发网络传输。

沿用已有 DownloadEngineTests，增加 SHA-256 正确／错误内容和无效格式的用例，没有新增测试类。命令 `env FERRY_MACOS_SDK=macosx bash Scripts/test-packages.sh --configuration release --filter DownloadEngineTests` 通过：46 个测试，包含原有暂停恢复、身份变化、MD5 失败、取消和预算调整，以及本次 SHA-256 验证。证据：`.build/v3-download-tests.log`。

目前提供引擎能力，原始摘要关联、结果状态展示、清单导入导出及分享清理门槛仍需 V3-T11／V3-T14 接入；不能把所有现有云端下载宣称为已有可信 SHA-256 基准。

## 共享连接与限速预算基础

DownloadKit 新增 `TransferBudget`：可取消的 FIFO 连接许可、异常自动释放、上传／下载分别聚合限速、更新配置、关闭和资源快照。回读使用下载方向。每方向仅在确有等待时保留一个弱引用计时任务，空闲即停止；调用方必须按有界缓冲消费额度，并限制实际 worker 数量。

独立临时程序和主代理复跑共通过 11 项检查，含 200 次取消／授予竞态、许可异常释放、聚合限速、方向独立、取消排队、设置唤醒、关闭清理及空闲对象释放。同方向合计 100 kB 在 100 kB/s 预算下耗时约 0.94 秒，允许约 100 毫秒突发。证据：`.build/transfer-budget-validation/result-root.txt`。本文件也已随上述包测试编译通过。
