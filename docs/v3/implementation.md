`FerryCore/UploadSource.swift` 已提供流式源文件扫描、权限书签、文件身份、完整 SHA-256／MD5／SHA-1、首 256 KiB MD5 及指定分块指纹。内容读取缓冲为 1 MiB；扫描通过事件逐项交付，包含隐藏文件和空目录，重叠选择去重，符号链接与不可读项目有独立问题记录。
