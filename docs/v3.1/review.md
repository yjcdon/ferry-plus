## 审查发现与关闭

1. 下载移除上一确认的迟到关闭事件可能取消下一确认：按当前阶段和展示标志核对，独立反例与回归已通过，随F04提交。
2. 系统文件导出/导入取消不调用原completion：原模拟取消的证据不足。`0e876de`改独立onCancellation，并用唯一面板请求ID释放载荷；同文件两代回调也不串用。真实面板验收仍在T21。
3. published已落盘而旧proof归档失败时，真实重试会绕过checkpoint：`d5bcf05`在最终完成前复用归档步骤补齐。修复前真实公开路径反例失败，修复后30项重建/重试/移除验证通过；不是手工再调用检查点。
4. 独立上传文件选择面板没有明确宿主：`b89a96d`绑定实际上传页窗口，用弱引用避免新增窗口持有环。窗口归属正确，Space/实际文件选择仍待T21。
5. 直接Xcode入口缺空版本显式门禁：`24f35fc`在Sources前复用版本读取并比对实际值；29项真实提取脚本检查通过，未安装或执行完整Xcode/触发CI。
