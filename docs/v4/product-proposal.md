# Ferry Plus 4.0 产品方案：双网盘文件工作区

状态：实施与验收中，实际进度见 [实施记录](implementation.md)。日期：2026-10-28。首版展示约定：沿用当前网盘下载页的可展开、可勾选列表。

## 1. 与已有方案的关系

4.0 是在已发布 3.1 基础上的交互改版：把百度、夸克的文件浏览放到主窗口，在当前目录完成上传、下载、新建文件夹和删除，传输进度继续集中管理。

继承 [3.0 功能清单](../v3/features.md) 的上传、下载、后台内容校验、网盘管理能力，以及 [3.1 优化方案](../v3.1/features.md) 的简洁、低维护成本和数据兼容目标。本方案替代旧独立窗口和重复入口约定；按用户最新要求，普通下载不再展示手动摘要、历史版本和 JSON 清单选择，后台校验与旧任务数据兼容继续有效。

适用对象仍是使用 Apple Silicon Mac 的百度、夸克用户；每家同时登录一个账号，两家可同时使用。延续 macOS 14 及以上、原生 SwiftUI、独立 App 和现有 Homebrew 分发方式。

## 2. 目标、问题与范围

**目标：用户先找到网盘中的位置，再就地完成文件操作，减少重复选择网盘、目录和往返弹窗。**

4.0 首版直接复用当前网盘下载页的列表外观：文件夹展开箭头、勾选框、图标、名称、修改日期和大小。保持列表展示，不引入另一套表格行选择或图标视图。

当前上传、下载窗口各自包含部分目录浏览能力。下载窗口还承担删除、拖入上传，上传窗口承担目录导航和建文件夹；用户为管理同一个目录，需要在不同入口间切换。4.0 将这些能力整合为常驻文件页。

| 产品方法 | 对应能力 | 预期结果 |
| --- | --- | --- |
| 以网盘和当前目录组织操作 | 侧边栏网盘入口、文件列表、目录导航、当前位置展示 | 明确操作的是哪家网盘、哪个账号和目录 |
| 在文件所在位置完成操作 | 上传、拖放、下载、新建文件夹、批量删除 | 复用当前选择，不重复选择网盘与目录 |
| 文件管理与传输进度各有固定位置 | 文件工作区、现有传输列表、上传结果定位 | 提交任务后可以继续浏览，随时查看进度和结果 |

本版一次性交付上述交互整合。重命名、移动、复制、跨网盘搬运、预览、同步盘、回收站管理和全盘搜索不纳入本版。夸克安全覆盖、极端异常全自动恢复沿用已有延期决定。

## 3. 使用场景与主流程

| 场景 | 用户流程 | 结果 |
| --- | --- | --- |
| 浏览并下载 | 选择网盘 → 进入目录 → 选择文件或文件夹 → 下载确认 → 查看传输 | 下载加入现有队列，文件页留在原位置 |
| 上传到指定目录 | 选择网盘 → 进入目录 → 选择或拖入本地文件 → 上传确认 | 网盘和目标目录自动带入，提交后继续浏览 |
| 整理目录 | 进入目录 → 新建文件夹或选择项目删除 → 查看列表更新 | 操作位置和影响范围清楚 |
| 查看上传结果 | 传输详情 → 查看云端结果 | 打开所属网盘的准确目录，不再打开另一套浏览弹窗 |
| 同时使用两家网盘 | 百度浏览或提交任务 → 切换夸克 → 返回百度 | 两家保留各自浏览位置，已提交任务继续执行 |

未登录时，在对应网盘页展示登录入口，完成登录后读取该账号目录。登录失效时提示处理该账号，另一家网盘仍可使用。

## 4. 主窗口与导航

```text
侧边栏                         内容区

网盘                           百度网盘 · 账号名称
  百度网盘                     返回上级    根目录 / 工作资料
  夸克网盘                     上传  新建文件夹  刷新  搜索当前目录

传输                           名称           修改日期        大小
  全部                         ▸ ☐ 项目资料   ……              —
  进行中                         ☐ 说明.pdf   ……              2 MB
  已完成
  失败

账号与设置
```

- 侧边栏固定显示百度、夸克两个网盘入口；内容区不再重复显示网盘页签或下拉选择。
- 首次打开及无法恢复页面时默认进入百度网盘；之后恢复上次主页面。每家账号分别记住浏览目录，切换不影响另一家位置。
- 传输分类保留全部、进行中、已完成、失败；进入传输页后保留全部网盘／百度／夸克筛选，以及全部传输／下载／上传筛选。
- 浏览网盘与筛选传输相互独立。点击夸克文件页不隐式改变传输列表的筛选条件。
- 文件页标题展示网盘和账号，路径栏展示当前目录；侧边栏底部保留“账号与设置”。账号菜单和设置沿用现有登录状态规则。
- 工具栏随页面变化：文件页展示文件操作；传输页展示分享链接、传输控制、详情与任务搜索。分享链接功能仍可通过应用菜单访问。
- 窗口缩小时，名称列优先保留空间，日期和大小列对齐；按钮不侵入搜索区域，长名称截断并可查看完整名称。

## 5. 文件页功能设计

### 5.1 列表浏览与目录导航

- 沿用当前下载页的树形列表：文件夹箭头展开／收起，行前勾选框选择，行尾展示修改日期和大小。文件夹大小显示“—”，未知信息不伪装成零；各层缩进只影响名称区域，行尾列保持对齐。
- 点击箭头仅展开／收起子项，不改变当前目录。双击文件夹可将该文件夹设为当前列表的根；提供返回上级和可点击的路径导航。双击普通文件不自动开始下载。
- 默认文件夹在前、名称升序；直接点击名称、修改日期、大小列标题排序，再点同一列切换升降序，当前列旁显示方向。不额外设置排序按钮或菜单；对每层已经加载的同级条目分别排序，父子关系保持不变。
- 沿用勾选方式支持单选、多选和全选，文件与文件夹可混选，不以 Command／Shift 行选择替代。勾选文件夹表示选择整个目录，子项显示随父目录选中且不重复计数；取消父目录勾选不保留隐式子项选择。切换当前目录或网盘时清空选择。
- 搜索仅按名称筛选当前列表根目录的直接子项，搜索期间收起子树，不递归搜索，也不影响传输任务搜索。匹配到文件夹不表示其内部文件名称匹配；勾选该文件夹仍表示整个目录。目录有分页时，搜索和全选必须基于完整直接子项；未读完时明确加载状态。
- 搜索或收起文件夹时，清除不再显示的独立子项勾选；仍勾选的父目录继续代表整个目录。全选勾选当前根下可见的顶层项目，避免父子重复。进入其他目录清空搜索条件；刷新同一目录保留搜索与排序，保留可核实仍存在且可见的勾选项。
- 文件列表、展开子目录和明细读取的加载文字统一为“加载中”；空目录、无搜索结果、读取失败和未登录分别展示对应状态。刷新失败时保留原列表并提示更新失败，不把旧内容当作最新结果。
- 原目录失效时提示并允许返回可访问的上级或根目录，不静默把后续上传改到根目录。换账号后从新账号根目录开始。
- 从历史上传结果直接定位时，夸克可能只有准确目录身份而没有完整祖先路径；展示已知位置与“…”并提供回到根目录，父级未知时不提供虚假的上一级，不为补齐路径扫描全盘。

### 5.2 上传与拖放

- 点击“上传”选择本地文件或文件夹，也支持 Finder 拖入文件页；均打开同一精简上传确认面板。
- 拖到列表空白区域，目标是当前列表根目录；拖到任意层级的文件夹行，目标是该文件夹，并明确高亮。展开、收起或勾选文件夹不改变工具栏上传和新建的目标；普通文件行不作为上传目录，不产生覆盖手势。
- 确认面板展示待上传项目、网盘、账号、准确目标路径和同名处理；支持继续添加、移除本地项目及取消。整块添加区域可点击或拖放。
- 面板不重复提供网盘页签和目录浏览器。需要换目标时取消确认，返回文件页选择目录；已显示的目标不能随后台导航或换号改变。
- 确认后才创建上传任务；拖入本身不上传。保留现有权限、空间、重复任务提示与内容校验流程。
- 同名文件默认保留两份，两家均支持跳过，百度保留安全覆盖；同名目录沿用合并规则，夸克不提供尚未实现的覆盖能力。
- 上传提交成功后关闭确认面板，留在文件页。显示已加入传输的反馈和查看入口，不强制跳转。
- 保留从传输页拖入文件的可达路径：先进入文件页并保留本批本地选择，明确选择或确认网盘与目标，再进入上传确认。原传输筛选“全部网盘”不能充当上传目标，导航也不能静默丢弃这批文件。

### 5.3 下载

- 选中文件或文件夹后，通过工具栏或右键菜单下载；未选择时下载操作不可用。
- 下载确认面板展示所选项目、来源账号和本地保存位置，沿用默认下载目录，允许修改本次位置。
- 普通下载确认只展示文件、来源和保存位置，不提供手动摘要、历史版本或 JSON 清单配置，也不要求用户理解或选择校验算法。
- 下载后台沿用服务端可用摘要和现有引擎检查；上传仍完整回读校验。没有可靠依据时不冒充校验成功，不静默选择某条历史记录作为当前文件的依据。失败提示具体问题，普通下载不被校验配置阻塞。
- 确认后加入现有下载队列并返回当前目录；取消不创建任务。目录下载沿用现有相对路径处理，不新增空目录下载承诺。

### 5.4 新建文件夹

- 工具栏提供“新建文件夹”，在当前目录输入名称后确认；取消不创建。
- 成功后更新当前列表，清晰标识新目录。搜索条件使新目录不可见时提示原因，提供清除筛选查看的操作。
- 名称不合法、同名冲突、无权限或服务端失败时显示原因，不能显示创建成功。

### 5.5 删除

- 工具栏与右键菜单支持单项或批量删除，文案明确“移到网盘回收站”。
- 确认内容包含网盘、账号、项目数量、名称和文件夹递归影响；取消不执行。
- 只处理当前页面明确勾选的项目，父子去重并使用各自准确父目录。筛选后隐藏的独立勾选项不属于本次范围；勾选父目录仍代表整个目录。右键独立勾选的行作用于当前勾选组；右键未勾选或仅继承父目录选中的行，只操作该行。
- 只有服务端确认成功的项目才从列表移除；部分失败显示失败项目及原因，允许用户重新处理。
- 删除云端文件与移除传输任务是不同操作。删除不同时移除任务记录或本地文件；涉及进行中传输的目录或文件时，在确认中提示可能导致任务失败，不静默取消任务。

## 6. 旧入口与现有能力的承接

| 现有入口或能力 | 4.0 去向 |
| --- | --- |
| 主工具栏“从我的网盘下载” | 删除该独立入口，由侧边栏网盘文件页和选中后的下载操作承接 |
| 主工具栏“上传文件” | 删除全局独立按钮，由文件页上传和拖放承接 |
| 完整网盘下载弹窗 | 文件浏览、选择、删除移入文件页；下载确认仅保留文件和保存位置，移除高级校验表单及临时状态 |
| 完整上传弹窗 | 目录导航和建文件夹移入文件页；本地项目、同名处理保留在精简上传确认面板 |
| 应用菜单“从我的网盘下载” | 改为打开网盘文件页的导航命令，不再打开旧弹窗 |
| 应用菜单“上传文件”与 Command-U | 文件页内使用当前目录；从传输页调用时先进入最近的网盘文件页（无记录则百度），展示目标后选择本地文件 |
| 搜索快捷键 | 文件页聚焦当前目录搜索；传输页聚焦任务搜索，文案与当前页面一致 |
| 上传详情中的云端目录、结果和备份定位 | 导航到文件页的所属账号、准确目录；可确定目标文件时定位该行。原账号未登录时提示登录，不跳到其他账号的同名目录 |
| 分享链接、剪贴板识别 | 沿用分享识别、转存、文件选择和下载流程；不受当前浏览网盘约束 |
| 传输列表及详情 | 保留筛选、暂停、继续、重试、移除、源文件重定位，以及已有记录查看和清单导出；旧任务的校验依据继续可读取 |

“去掉入口”是去掉重复的独立窗口入口。文件页内的上传、下载操作和必要确认仍然存在，全部路径最终进入同一套操作流程。

### 6.1 改版后可以简化的内容

| 现有内容 | 4.0 处理方式 | 简化后的结果 |
| --- | --- | --- |
| 独立“从我的网盘下载”完整窗口 | 浏览移到主文件页，下载仅保留确认面板 | 不再为下载重新打开一套文件列表 |
| 上传完整窗口中的目录浏览、新建文件夹和网盘页签 | 由主文件页确定目标，上传面板只确认本地项目和同名处理 | 不重复选择网盘和目录，不维护两套目录导航 |
| 主工具栏的网盘下载、上传独立入口 | 移除，由文件页内的操作承接 | 主工具栏随页面显示当前可执行操作 |
| 两个完整窗口各自的网盘切换和目录加载 | 合并到每家一份的工作区浏览状态 | 同一账号的位置、刷新和错误展示有统一来源 |
| 下载窗口里再打开上传窗口、上传后连带关闭下载窗口 | 由主窗口直接管理精简确认面板 | 不再维护父子弹窗关闭联动 |
| 上传详情里再打开一套云端浏览窗口 | 关闭详情后定位到主文件页 | 云端结果、备份和日常浏览共用页面 |
| 上传窗口专用的“最近上传目录”恢复流程 | 新上传一律使用文件页明确展示的目标 | 不在打开上传面板时另行恢复旧目录或覆盖当前目标 |
| 不同入口各自维护的待上传项目 | 合并为主窗口的一份待上传草稿，再生成固定目标的确认 | 拖放、按钮和快捷键复用同一流程 |
| 普通下载中的摘要输入、历史候选和 JSON 导入 | 删除表单及对应请求、草稿、校验模式和异步状态 | 用户选文件和保存位置即可下载，后台检查与历史任务兼容保留 |

这是界面与状态管理的简化。网盘协议、上传下载任务、同名处理、保存位置、校验与账号隔离继续复用；不能通过去掉这些业务能力减少代码。具体可删符号及清理条件见 [技术方案 §6.4](architecture.md#64-可简化与删除清单)。

## 7. 关键规则与依赖

1. **操作范围明确。** 文件操作绑定本次确认时的网盘、账号、目录和所选项目；切换页面不改变已提交任务。换号或登录状态变化导致原确认失效时，提示重新确认。
2. **批量范围与界面一致。** 文件批量操作仅针对当前列表中可见且明确勾选的项目，勾选文件夹包含其全部内容，父子不重复操作。传输批量操作继续按网盘、方向、状态、搜索及选择确定范围；文件选择不能成为传输命令的操作对象。
3. **目录变化及时可见。** 新建与删除完成后更新目录；上传任务结束后刷新其目标目录。用户已离开时不抢回页面，返回该目录时读取变化。失败或取消的上传也可能留下已成功文件，目录应能反映服务端实际状态。
4. **传输完成语义不变。** 上传字节达到 100% 不等于完成；沿用现有完整内容核验。下载没有可信校验基准时，不能显示为内容已验证。
5. **保留升级数据。** 账号、钥匙串访问、任务历史、设置和校验记录继续使用；界面改版不要求重新登录或重新创建任务。
6. **保持轻量。** 文件页按需读取目录，后台传输复用现有能力。保持 Ferry 风格，不为浏览增加全盘扫描或持续全盘轮询；不承诺未经测量的性能和包体下降。

现有代码已具备两家目录读取、上传、下载、建目录和删除能力，产品方案不依赖新增网盘协议。主要改动在页面组织、目录与选择状态、确认流程和结果刷新。服务端权限、速率、容量及登录有效性仍决定实际操作结果。

## 8. 产品验收口径

| 验收项 | 完成标准 |
| --- | --- |
| 主页面组织 | 侧边栏可直接进入两家文件列表与传输分类；没有重复网盘切换控件和旧完整浏览弹窗入口 |
| 浏览与定位 | 列表样式与当前下载页一致，支持文件夹展开／收起、勾选及整体目录选择；可进入、返回、排序、搜索；各层日期和大小列对齐，切换后无跨账号目录或选择残留 |
| 上传闭环 | 点击、空白区域拖放、文件夹行拖放均显示正确目标；取消不上传；确认后队列可见且可继续浏览 |
| 下载闭环 | 文件和文件夹选择后直接确认保存位置并下载，无摘要／历史版本／JSON 配置；取消不创建任务，后台检查继续有效 |
| 目录管理 | 新建、批量删除及部分失败反馈正确；范围与当前选择一致；操作后目录更新 |
| 入口完整 | 菜单、快捷键、传输页拖放、分享链接和云端结果定位均有明确路径，不再调出旧完整窗口 |
| 传输兼容 | 原有暂停、恢复、重试、同名处理、校验、任务移除及数据保留规则有效；文件页操作不误触传输批量命令 |
