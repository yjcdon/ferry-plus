# Ferry Plus 新增功能清单

## 1. 定位与交付范围

在 Ferry 现有基础上增加夸克网盘，用户通过同一个简洁的原生 Mac 应用下载百度、夸克的分享文件，以及这两家网盘中自己账号内的文件，并能暂停、重试和恢复下载。

网盘来源只有百度和夸克。“从我的网盘下载”是浏览这两家已登录账号内文件的入口，与“添加分享链接”区分下载来源方式。

核心目的：保留 Ferry 的操作体验和已有下载能力，让两家网盘共用一套任务管理，减少重复操作和独立维护成本。

| 项目 | 确定范围 |
| --- | --- |
| 平台 | Apple Silicon Mac，arm64，macOS 14 及以上 |
| 应用 | Ferry Plus，Swift / SwiftUI 原生应用 |
| 网盘 | 仅百度网盘、夸克网盘；保留百度，新增夸克 |
| 账号 | 每家网盘同时保留一个登录账号；百度和夸克可同时登录 |
| 交付方式 | 本文所有功能一次性交付，不划分首版或后续版本 |
| 界面方向 | 延续 Ferry 的状态侧边栏、任务列表、详情面板和原生设置窗口；侧边栏顶部筛选网盘，底部展示对应账号入口 |
| 仓库交付 | 暂时移除介绍网站及专用部署配置，项目介绍保留在 README，安装包通过本仓库 Releases 提供 |

## 2. 产品解决思路

| 方法 | 支撑能力 |
| --- | --- |
| 按来源识别、按账号执行 | 分享识别、双网盘登录、任务绑定网盘和账号 |
| 两家共用操作流程 | 统一添加任务、文件选择、状态列表和详情 |
| 保留下载进度和源文件身份 | 分片续传、地址刷新、退出恢复、失败重试 |
| 清理范围由任务确定 | 独立转存目录、完成后清理、本地文件移到废纸篓 |

## 3. 核心使用流程

### 分享下载

粘贴分享文案 → 识别网盘和提取码 → 检查对应网盘登录 → 展示分享文件 → 选择文件和保存位置 → 创建任务专用转存目录 → 转存并确认完成 → 获取下载地址 → 下载 → 按设置清理转存内容。

### 百度／夸克账号内文件下载

点击“从我的网盘下载” → 当前筛选为百度或夸克时默认进入对应网盘，“全部网盘”时先选择百度或夸克 → 检查该网盘登录 → 浏览目录 → 选择文件和文件夹 → 选择保存位置 → 展开所选目录并创建任务 → 直接下载。

### 中断恢复

启动应用 → 读取任务、账号和分片进度 → 按任务归属校验登录 → 获取当前可用地址 → 恢复未完成文件。手动暂停的任务保持暂停；退出前尚未确认完成的转存任务显示失败原因，由用户重试。

### 4.6 网盘切换、账号展示与操作范围

**账号展示与新建任务**

| 场景 | 规则 |
| --- | --- |
| 筛选百度或夸克 | 底部显示该网盘图标、账号名称和登录状态；未登录显示“登录百度网盘…”或“登录夸克网盘…”，登录失效提供对应的重新登录入口 |
| 筛选全部网盘 | 底部显示“账号与登录”，一级菜单各用一行展示百度、夸克及账号名称；状态和操作收进对应网盘的二级菜单，底部保留设置入口。正常登录只显示“退出登录”，未登录显示“登录”，失效才显示“重新登录”；夸克登录校验遇到网络等问题时提供“重试”，不常驻手动验证。单一网盘筛选沿用相同菜单层级，只显示对应网盘 |

| 添加分享链接 | 手动粘贴和剪贴板识别均按链接确定百度或夸克；添加窗口显示识别结果并使用对应账号。例如筛选夸克时添加百度链接，仍创建百度任务 |
| 从我的网盘下载 | 仅浏览百度或夸克账号内的文件；单一网盘筛选时默认进入该网盘，全部网盘时先选择百度或夸克，再进入对应登录或文件选择流程；入口可在未登录时使用 |
| 创建后不符合当前筛选 | 保留当前列表，提示“已添加百度网盘任务”等来源信息，并提供“查看任务”；点击后切到该网盘的“全部”分类、清空搜索并选中新增任务 |

**批量操作**

| 操作入口 | 目标范围与交互 |
| --- | --- |
| 工具栏暂停／继续 | 作用于当前列表内符合操作条件的任务，与是否选中无关。存在可暂停任务时显示暂停；否则有可继续任务时显示继续；均无则禁用。提示注明“暂停当前列表的 3 个任务”等实际目标数量 |
| 应用菜单中的列表级操作 | 使用“暂停当前列表”“继续当前列表”等文案，与工具栏采用相同范围；没有活动任务列表窗口时禁用 |
| 选中项操作 | 详情面板、右键菜单及对应菜单项只处理当前列表中选中的任务；全选同样只选当前列表。右键未选中行时，仅以该行为操作对象 |
| 状态与账号条件 | 各动作分别判断可执行任务；准备和转存阶段不计入暂停目标。本地暂停、查看和移除不因未登录而禁用；需要网盘访问的继续或重试检查任务账号，账号不匹配时提供登录原账号入口 |
| 移除确认 | 沿用现有必要确认，展示操作对象、数量及远端清理范围；混合移除时分别列出两家的任务数，以及按各自设置会清理的任务目录数。确认固定本次目标与清理选择，执行时检查最新状态及账号；新出现的任务不加入操作，清理设置后续变化不扩大已确认范围 |
| 批量结果 | 每个目标使用自己的网盘和账号处理；某项失败保留该项原因，其余可执行项继续处理 |

“全部网盘”仍受状态分类和搜索限制。只有处于“全部网盘 + 全部分类 + 空搜索”时，列表级操作才覆盖所有任务中符合操作条件的项目。

### 4.7 仓库整理

## 6. 关键规则

1. 网盘来源和所属账号创建后固定。昵称用于展示，不作为账号身份。
2. 网盘筛选决定列表、账号展示及账号文件入口的默认来源；分享来源由链接确定。切换筛选不改变已有任务执行或账号归属。
3. 分享任务执行期间保留转存内容，供地址刷新和失败重试使用；下载完成或用户主动移除任务时，按对应网盘清理设置处理任务目录，清理开关关闭时继续保留。
4. 清理、转存重试和移除必须使用已记录的任务目录归属。无法确认目录归属时保留远端文件并提示。
5. 百度／夸克账号内文件下载只读取源文件。任务本地删除操作与网盘源文件清理分别处理。
6. 两家共用全局下载资源上限；连接数设置不代表下载速度承诺，速度受账号权益、服务端和网络影响。
7. 登录、转存和地址刷新中的失败不得通过切换到另一网盘、另一账号或替代内容继续执行。
8. 批量操作先确定当前列表或选中项范围，再判断动作是否可执行；按任务 ID 固定本次操作对象，发起时不在范围内的任务不受影响。

## 7. 整体验收标准

| 场景 | 验收结果 |
| --- | --- |
| 原生体验 | 主布局和核心操作保持 Ferry 风格，新增入口能直接识别网盘来源 |
| 双网盘并行 | 两家同时登录并混合下载；切换网盘筛选、退出其中一家均不误操作另一家 |
| 网盘筛选与统计 | 三个网盘筛选项与四种分类、搜索组合正确；分类数和列表数符合 4.6 的统计口径，切换筛选后后台下载继续 |
| 账号展示 | 全部网盘时可分别查看及操作两家账号；单一网盘只显示对应账号；未登录、失效和换号后入口、任务归属正确 |
| 新建任务来源 | 筛选夸克时粘贴百度链接仍创建百度任务，并可定位新增任务；账号文件入口按单一网盘默认进入、全部网盘先选来源 |
| 批量范围 | 工具栏、菜单、快捷键及右键操作遵守当前列表或选中项范围；空搜索结果不操作隐藏任务，移除确认不扩展目标 |
| 夸克分享 | 无提取码、带提取码、分页、多层目录、多文件选择均能正确转存和下载 |
| 百度／夸克账号内文件 | 两家均可下载所选文件及目录，本地结构正确，网盘源文件保持原样 |
| 大文件恢复 | 暂停、退出重开、网络恢复及地址失效后可继续；源内容变化时不拼接错误内容 |
| 清理与删除 | 只清理任务拥有的转存目录；本地关联文件进入废纸篓；失败项可定位 |
| 转存中断 | 服务端接受后本地退出，重开重试可按记录查询结果；结果不明时不重复提交、不将部分文件当作完成 |
| 兼容性 | 现有百度任务与分片样本可正确读取和续传；未知格式提示而非误判归属 |
| 应用交付 | arm64 安装产物可在目标 Mac 安装和运行，macOS 14 起的系统 API 可用性符合声明 |
| 网站移除 | 仓库无网站源码及专用部署配置，README 无失效的网站入口；应用资源、构建发布及 README 图片引用完整 |
