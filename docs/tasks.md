# Ferry Plus 实施任务清单

## 1. 使用规则

依据 [功能清单](features.md) F-01～F-29 和 [架构设计](architecture.md) 拆分。本文描述实施顺序，全部任务属于同一次交付。状态以任务勾选及第 6 节执行记录为准；已有 Ferry 能力以迁移和验证为主。

- 按任务依赖推进；只有完成实现及列出的验证，才勾选任务。
- 每项任务记录实际改动、验证结果及未解决问题；接口验证记录脱敏证据，不把文档或静态检查当作真实下载通过。
- 复用现有测试与验证工具，未经明确要求不新增测试类；代码变更按影响范围构建，纯文档调整不构建。
- 涉及删除的仓库文件先移动到废纸篓。
- 首先交付可运行的夸克登录闭环；用户完成官方登录后，后续接口验证复用保存的有效会话。任务编号保持稳定，执行顺序以本节依赖表和任务前置条件为准。

## 2. 实施顺序与依赖

| 顺序 | 任务 | 进入条件与完成结果 |
| --- | --- | --- |
| 最小登录闭环 | T-02 → T-01 → T-07 → T-08 | 建立独立应用身份，实现会话导入、校验与保存，嵌入官方登录页；用户完成官方登录后确认会话可用 |
| 登录后自动验证 | T-21 | 复用同一会话自动验证目录、分享、转存、下载和续传接口，为后续正式适配提供依据 |
| 公共模型与正式适配 | T-04 → T-05、T-06 | 扩展公共契约，接入两家实现及任务存储；沿用登录闭环已有的账号模型和会话 |
| 任务与下载链路 | T-09～T-12 | 完成准备、转存、地址解析、共享下载、设置及中断恢复 |
| 原生界面与操作 | T-13～T-18 | 完成两种添加入口、网盘筛选、账号展示、清理、批量操作与生命周期适配 |
| 仓库整理 | T-03 | 网站移除独立于登录闭环，登录优先完成后安排，最终验收前完成 |
| 整体验收与安装产物 | T-19～T-20 | 复用有效会话完成自动回归及必要的界面验收，生成并验证 arm64 安装产物 |

具体依赖以各任务为准。T-01、T-07、T-08 不依赖分享、转存、下载或旧任务迁移完成，避免登录被后续功能阻塞。首次登录由用户完成；会话有效时，后续实现和验证持续复用该状态，不要求每项功能重新扫码。登录过期、验证码或系统凭据访问确认出现时再由用户处理，处理后继续验证。

## 3. 任务明细

### 先完成夸克登录闭环

- [x] **T-02 建立 Ferry Plus 应用身份与 arm64 构建基础**

  **依赖：** 无。**对应功能：** F-01、F-23。

  **涉及范围：** Xcode 工程、构建配置、应用显示名、JobStore 数据目录、CredentialStore 钥匙串空间。

  **工作：** 使用 Ferry Plus 的应用标识和显示名，独立保存任务、设置与凭据；配置 arm64 和 macOS 14 最低版本，核对资源及权限配置。

  **完成标准：** 基础应用可在 Apple Silicon Mac 构建启动；与原版 Ferry 的数据、钥匙串空间互不覆盖；不自动导入原版数据；原项目许可声明保留。

- [x] **T-01 实现最小夸克会话校验客户端**

  **依赖：** T-02。**对应功能：** F-03、F-04、F-22。

  **涉及范围：** QuarkKit 登录及账号接口、Package.swift。

  **工作：** 从官方页面 Cookie 构造候选会话，实现 Cookie 补全、稳定账号标识读取和最小网盘鉴权请求。集中处理 Cookie 域、路径、有效期与接口错误；网页负责实际短信、扫码和安全验证流程。

  **完成标准：** 最小客户端可构建，能导入官方网页会话并校验账号及根目录；未登录或空账号响应不误报成功。真实网页登录贯通证据在 T-08 完成，此任务不要求实现分享、转存或下载。

- [x] **T-07 建立双网盘账号模型、会话保存与验证复用入口**

  **依赖：** T-02、T-01。**对应功能：** F-02、F-04、F-14、F-22、F-23。

  **涉及范围：** Provider、AccountKey、AccountSummary、AppModel、CredentialStore、账号校验与验证入口。

  **工作：** 建立仅含百度／夸克的最小账号模型，两家分别维护一个活跃会话和会话版本；凭据分别保存、读取、更新及退出。统一提供按 AccountKey 获取会话的入口，供后续任务和自动验证复用；验证入口使用应用共用客户端及凭据存储，不另复制 Cookie 建立第二套登录流程。

  **完成标准：** 保存和恢复的会话可交给同一客户端校验，Cookie 更新回写原凭据条目；退出或换号只影响对应会话，旧响应不覆盖新账号；账号失效给出对应入口。此时不要求完成 Job 存储迁移、分享适配或文件树，实际任务账号隔离在 T-04、T-09 和后续回归中验证。

- [x] **T-08 接入夸克官方登录页**

  **依赖：** T-01、T-07。**对应功能：** F-03、F-04、F-22。

  **涉及范围：** 官方登录窗口、共用 WebLoginSession 与 WebViewContainer、Cookie 监听、AppModel 登录入口。

  **工作：** 提供可直接进入的夸克官方登录页，复用百度 WebView 容器和 Cookie 监听。使用官方提供的登录方式，优先按用户偏好选择短信登录；应用只显示页面加载与账号校验状态，支持重新加载、重试及取消。官方登录完成后校验账号和网盘权限，通过才保存凭据，不等待最终侧边栏或下载功能完成。

  **完成标准：** 官方页面完成登录后显示正确账号；重启应用可恢复有效会话，自动验证入口可用同一会话执行鉴权读取。取消后停止 Cookie 监听和校验，日志不包含登录秘密。首次登录成功后进入 T-21，无需为每个功能重新登录；短信是否能自动接收与填写需另外验证当前环境能力，不作为已实现能力。

### 登录后复用会话自动验证

- [x] **T-21 复用已登录会话自动验证夸克关键接口**

  **依赖：** T-08。**对应功能：** F-03、F-04、F-07、F-08、F-10、F-11、F-15、F-19、F-22、F-23。

  **涉及范围：** 共用 QuarkKit 客户端、T-07 会话复用入口、架构第 8 节接口及脱敏验证记录。

  **工作：** 用户扫码完成后，由自动验证入口读取并校验已保存会话，按需补充最小接口调用，验证目录分页、分享及提取码、任务专用目录、转存回执与状态查询、下载请求头、Range、续传、地址刷新和清理。记录真实域名、参数、字段、错误及文件校验结果，为 T-05 的正式实现提供依据。

  **完成标准：** 同一会话完成真实目录读取、分享转存及样例下载，覆盖分页、多层目录、转存中断核对和续传；测试目录归属明确，只清理本次创建的目录。验证程序与后续客户端共用会话和 Cookie 更新逻辑，不导出明文凭据；接口限制或无法触发的场景保留待验证记录，不伪造通过。

  **完成依据：** 复用已保存登录，真实分享 models 展示 125 个子项及尾部，带提取码分享错误后修改成功；多层选择转存、下载、清理及真实 HTTP 206 续传通过。E36F3C6D 在首批回执落盘、次批未提交时结束进程，重开后人工重试沿原首批回执查询，再完成两批、66615 字节下载及清理；本地校验值与此前相同样本一致，远端重新浏览只保留原有目录。自然 CDN 地址过期未实测，地址失效后按位移刷新由正式共享引擎的受控 HTTP 回归覆盖；后续页失败也由真实客户端的受控响应回归覆盖，不写成真实服务错误现场。

  **后续复用：** T-09～T-19 在各功能实现后，继续使用同一会话验证应用编排、共享引擎和恢复行为。T-21 的接口通过不能替代这些应用级验收；会话失效时通知用户重新登录，恢复后继续未完成项。

### 公共模型与正式适配

- [x] **T-04 落实公共模型、轻量策略及百度调用方迁移**

  **依赖：** T-21。**对应功能：** F-05、F-07、F-08、F-10、F-14、F-15。

  **涉及范围：** FerryCore 的 Netdisk、Job、JobFile、公共远端引用、下载上下文、百度适配器，以及受类型变更影响的调用方。

  **工作：** 沿用 T-07 已建立的 Provider、AccountKey 与账号摘要，补齐 RemoteEntry、ShareHandle、TransferDirectory、TransferProgress 和带版本的 DownloadContext；任务区分分享与账号内文件，保存账号名称快照。将公共协议从百度专属类型中解耦，落地百度适配器，并同步迁移现有百度链路的调用方。

  **完成标准：** 公共界面模型和调度接口不暴露百度专属类型；百度路径和夸克 fid 分别表达；百度已有链路通过受影响构建与现有验证。“全部网盘”只存在于界面筛选，不进入任务归属。已有登录会话不因本次迁移丢失，任务归属校验在本次调用方迁移与 T-09 中接通。

  **完成依据：** Netdisk 公共协议及 RemoteReference 已落地，Provider 仅有百度／夸克；新任务固定 AccountKey，执行前校验归属。包测试、arm64 App 构建、两家重启恢复和百度真实转存下载清理均已验证，详见 implementation.md。

- [x] **T-05 实现 QuarkKit 与夸克适配器**

  **依赖：** T-21、T-04。**对应功能：** F-03、F-05、F-07、F-08、F-10、F-11、F-15、F-22。

  **涉及范围：** 新增 QuarkKit、FerryCore 夸克适配器、Package.swift。

  **工作：** 沿用 T-01 的登录客户端和 T-21 的验证结果，补齐正式文件、分享、转存提交与状态查询、下载地址及清理接口；集中处理 Cookie 更新、分页、请求头和业务错误；通过适配器转换为公共模型，复用同一账号会话。

  **完成标准：** QuarkKit 与 BaiduKit 独立，公共层无需拼装夸克请求；分页失败不返回假完整列表，鉴权失败不当作空目录；转存提交回执能在轮询前交给调度层保存。

  **完成依据：** 两家 SDK 独立，QuarkKit 集中处理分页、鉴权和业务错误，适配器先保存 task_id 回执再轮询；持久化失败及转存部分结果已有回归。真实夸克分享已展示超过 100 项，并完成转存下载清理及中断恢复；后续页失败由受控响应回归验证，不描述为真实服务失败界面已实测。

- [x] **T-06 完成任务存储与旧格式兼容**

  **依赖：** T-02、T-04。**对应功能：** F-18、F-23、F-24。

  **完成标准：** 旧样本与新样本均能正确读写；未知格式或未知账号明确提示；任务 JSON 不包含 Cookie、分享会话令牌或下载直链；暂停标记和转存记录可恢复。完整启动恢复在 T-12 验证。

  **完成依据：** Job 编解码覆盖旧 accountUK、远端引用、新任务及暂停回执；未知版本拒绝，首次覆盖前备份。既有 JobModelTests、JobStateTests 和下载上下文迁移回归已通过；两家正常退出与异常关闭后的恢复见 T-12。自然 CDN 地址过期未实测，共享引擎失效恢复有受控回归。

### 任务与下载链路

- [x] **T-09 接入双网盘任务准备与转存编排**

  **依赖：** T-05、T-06、T-07。**对应功能：** F-07、F-08、F-10、F-14、F-18、F-22。

  **涉及范围：** JobCoordinator、两家适配器、TransferDirectory、TransferProgress。

  **工作：** 分享任务创建并记录专用目录，提交转存后立即保存服务端回执，再等待完成并列文件；账号内文件任务直接展开所选目录。准备和转存错误保留阶段、目录与已知结果。

  **完成标准：** 两种任务均生成完整文件列表和相对路径；转存确认前不开始下载；中断后优先查询原任务，结果不明时不自动重提、不把部分目录视为成功；账号内文件不创建转存目录。

  **完成依据：** 真实 Release 分享任务 8480957F 按根目录与深层目录分成两批，回执均完成后生成完整相对路径清单，下载 66615 字节并自动清理任务目录；重新浏览确认目录已消失，原有目录保留。账号文件直接下载已验证且不创建转存目录。已有正式实现回归覆盖已知回执先查询、未知提交不重发、回执写盘失败、结果不完整或大小不符不开始下载／清理；E36F3C6D 另补齐真实首回执落盘后结束进程、按原回执恢复并完成清理的证据。

- [x] **T-10 接入来源路由、共享下载和地址刷新**

  **依赖：** T-05、T-06、T-07、T-09。**对应功能：** F-14、F-15、F-16、F-19、F-22。

  **涉及范围：** RoutedDownloadSource、两家 DownloadSource、DownloadRequest、DownloadKit。

  **工作：** 按下载上下文选择网盘及账号，返回所需地址与请求头；两家共用一个引擎，支持单文件连接数覆盖。沿用地址刷新合并、分片范围及内容身份核对。

  **完成标准：** 混合下载始终遵守全局文件数和连接数上限；夸克参数不套百度会员规则；地址过期可刷新续传，权限或账号错误明确停止；内容变化、Range 不支持或响应不符时不拼接错误数据。

  **完成依据：** 两家真实同时下载及运行中并发调整、两家 HTTP 206 有界续传已有记录。既有套件补齐旧地址取得 64 KiB 后失效、刷新新地址从 65536 继续及最终内容一致；同大小文件的 ETag／Last-Modified 改变时拒绝追加，MD5 不符时不生成成功文件。权限、账号、Range 错误及单家连接数隔离已有回归，全量 25 套件 276 项通过。真实链接自然过期及更大规模下载仍在 T-21／T-19 验收，不替代为本地测试通过。

- [x] **T-11 整理通用设置、分网盘设置及代理更新**

  **依赖：** T-06、T-07、T-10。**对应功能：** F-09、F-16、F-20、F-21、F-23。

  **涉及范围：** FerrySettings、SettingsView、ProxySettings、客户端及引擎配置更新。

  **工作：** 通用设置保留下载目录、同时下载文件数、剪贴板检测和代理；两家分别保存转存目录、清理开关及单文件连接数。统一校验资源上限，代理变更同步作用于两家接口和下载会话。

  **完成标准：** 修改一家配置不覆盖另一家；默认保存及转存目录只影响新建任务；系统代理、自定义 SOCKS5 与认证配置均可工作；代理密码保存在钥匙串。

  **完成依据：** 两家独立配置、保存与转存位置快照、钥匙串密码存储已有源码和既有回归依据；系统模式、SOCKS5 认证及无认证的实际 API／下载链路已验证并恢复原设置。运行中全局文件数 2→1→2 的界面验证通过；单家连接数升降、共享最大值不变、暂停与重启、迟到入队及快速修改由实际本地 HTTP 分片回归覆盖，不扩写为所有真实网络条件均已验收。完整生命周期继续在 T-12／T-18 验证。

- [x] **T-12 完成暂停、重试、启动恢复与退出保存**

  **依赖：** T-06、T-09、T-10、T-11。**对应功能：** F-17、F-18、F-19、F-24、F-25。

  **涉及范围：** JobCoordinator、DownloadEngine、启动恢复顺序、shutdown。

  **工作：** 按任务归属恢复下载，手动暂停保持暂停；失败从对应阶段重试，已完成文件不重复下载。未确认转存进入可核对的准备失败状态；正常退出保存任务和分片。

  **完成标准：** 两家均覆盖暂停继续、正常退出重开、异常关闭、网络恢复、地址失效及转存中断；原账号缺失时保留进度；旧格式样本保持文件 ID 与分片位移。
