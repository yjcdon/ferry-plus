## T02 构建与验证

在 `desktop/` 执行 `go test ./...`、`go tool mygo vet` 和 `go tool mygo build -platform darwin/arm64,windows/amd64 -skip-dmg -skip-installer` 均通过。Mac App 使用临时签名，配置声明最低 macOS 14.0。产物位于 `.build/ferry-drive/`。安装验收由 T16 完成。

在 macOS 开发机上将固定版本 MyGo 的自动化插件仅链接到验证构建。原生元素树报告文本框、树形表格和弹窗，实际输入「测试文件」并确认后显示「已确认：测试文件」。这覆盖 C01 和 C65 的原型子场景。

## T04 存储验证

Go 记录保存在系统配置目录下的 `Ferry Drive/v5`。Mac 使用 Library/Application Support，Windows 使用 AppData 下的系统用户配置目录。每个记录用版本化 JSON 保存，长凭据用 AES-GCM 加密，系统凭据命名空间为 `io.github.yjcdon.FerryDrive.v5`。

Mac 的 `go test -race ./internal/store` 和 `go vet ./internal/store` 通过。测试覆盖检查点原子替换、进程退出释放锁、长凭据和损坏数据。隔离命名空间的实际钥匙串写入、读取、删除探针通过。Windows x64 测试二进制可生成。

## T03 平台适配验证

Mac 选取探针在同一 `NSOpenPanel` 混选一个文件和一个文件夹，返回两项有效书签。取消返回零项。用签名探针保存目录书签后移动目录，重启恢复到了新位置。定位和本地废纸篓使用 MyGo Shell。Windows 文件面板使用「上传所选项目」确认高亮的文件与文件夹，标准打开动作保留目录导航。

`go test -race ./internal/platform` 与两端目标的 `go vet ./internal/platform` 通过。Mac 自动化验证 PAC 和本地 SOCKS5 认证拒绝，路径测试覆盖越界和逃逸符号链接。Windows x64 测试目标已交叉编译，WinHTTP 实机及系统文件面板验证进入第二阶段。

## T07 主窗口验证

MyGo 在 Mac 的窗口使用系统按钮和实色工具栏。两家网盘与传输分类使用原生侧栏，分栏复用 MyGo Split。工作区保存页面、最近网盘、分栏宽度和展开状态，正常退出时写入 T04 的工作区记录。

Mac 运行验证构建，依次选择夸克、进行中、查看全部，输入搜索词并打开详情。无窗口测试覆盖同一路径、640×400 窄窗收起详情及偏好恢复。原生菜单和当前主题对照继续随 T17 验证，未接入的业务入口随各自任务开放。两端编译通过。

## T05 网盘协议验证

两家协议模块复用 Go HTTP 客户端，业务请求可注入 T03 代理。Mac 竞态测试和两端静态检查通过。离线样本核对分页、请求头、重定向、账号错误、签名以及上传回执。真实账号、目录与传输闭环随 T06、T08、T10～T12 验收。

## T06 登录验证

两家登录入口各开独立临时 MyGo 会话。官方页面使用系统代理，业务账号校验走 Go 客户端。凭据只在校验后加密保存，取消窗口会终止当前校验。百度继续等待网盘 STOKEN，并在现有条件满足时提供粘贴 Cookie 入口。固定版本 MyGo 通过页面完成事件和一秒轮询取得 Cookie。

Mac 使用本地页面样本实际打开两家登录窗，验证 WKWebView 加载、重新加载、取消与 Escape。账号测试验证取消校验结果、凭据写入和删除失败、退出隔离及百度离线恢复。Go 竞态测试、MyGo vet 及两端编译通过。真实账号扫码、百度 STOKEN 缺失时的服务端表现及 Windows WebView2 安装后的重试仍待验收。

## T08 目录验证

目录状态按账号和网盘独立维护。文件树通过 MyGo OutlineTable 展示，刷新保留有效列表，目录和账号变更取消过期读取。保存每家账号的目录路径及共享列宽。底层目录和树表测试覆盖排序、搜索、多选、父子去重、延迟结果及会话恢复。

Mac 使用隔离协议样本实际运行应用，展开目录、组合键选择父子项、按大小排序、中文搜索、双击进入目录、切到夸克再切回原路径均通过。竞态测试、MyGo vet 和 Mac／Windows 目标构建通过。

## T09 文件管理验证

新建返回准确远端对象后插入列表并聚焦名称。重命名和回收站按当前账号及原对象身份操作，确认框列出冻结的去重范围。Mac 运行验证覆盖右键新建、行内输入错误和修正、Esc 取消回收及确认回收。应用层测试另覆盖会话变化、同名和部分成功。竞态测试、MyGo vet、Mac 和 Windows 构建通过。真实网盘写入回归随 T18 验收。
