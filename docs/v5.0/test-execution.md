## T02 构建与验证

在 `desktop/` 执行 `go test ./...`、`go tool mygo vet` 和 `go tool mygo build -platform darwin/arm64,windows/amd64 -skip-dmg -skip-installer` 均通过。Mac App 使用临时签名，配置声明最低 macOS 14.0。产物位于 `.build/ferry-drive/`。安装验收由 T16 完成。

在 macOS 开发机上将固定版本 MyGo 的自动化插件仅链接到验证构建。原生元素树报告文本框、树形表格和弹窗，实际输入「测试文件」并确认后显示「已确认：测试文件」。这覆盖 C01 和 C65 的原型子场景。

## T04 存储验证

Go 记录保存在系统配置目录下的 `Ferry Drive/v5`。Mac 使用 Library/Application Support，Windows 使用 AppData 下的系统用户配置目录。每个记录用版本化 JSON 保存，长凭据用 AES-GCM 加密，系统凭据命名空间为 `io.github.yjcdon.FerryDrive.v5`。

Mac 的 `go test -race ./internal/store` 和 `go vet ./internal/store` 通过。测试覆盖检查点原子替换、进程退出释放锁、长凭据和损坏数据。隔离命名空间的实际钥匙串写入、读取、删除探针通过。Windows x64 测试二进制可生成。

## T03 平台适配验证

Mac 选取探针在同一 `NSOpenPanel` 混选一个文件和一个文件夹，返回两项有效书签。取消返回零项。用签名探针保存目录书签后移动目录，重启恢复到了新位置。定位和本地废纸篓使用 MyGo Shell。Windows 文件面板使用「上传所选项目」确认高亮的文件与文件夹，标准打开动作保留目录导航。

`go test -race ./internal/platform` 与两端目标的 `go vet ./internal/platform` 通过。Mac 自动化验证 PAC 和本地 SOCKS5 认证拒绝，路径测试覆盖越界和逃逸符号链接。Windows x64 测试目标已交叉编译，WinHTTP 实机及系统文件面板验证进入第二阶段。

## T07 主窗口验证

MyGo 在 Mac 的窗口使用系统按钮和实色工具栏。两家网盘与传输分类使用原生侧栏，分栏复用 MyGo Split。工作区保存页面、最近网盘、分栏宽度和展开状态，正常退出时写入 T04 的工作区记录。

Mac 运行验证构建，依次选择夸克、进行中、查看全部，输入搜索词并打开详情。无窗口测试覆盖同一路径、640×400 窄窗收起详情及偏好恢复。原生菜单和当前主题对照继续随 T17 验证，未接入的业务入口随各自任务开放。两端编译通过。

## T05 网盘协议验证

两家协议模块复用 Go HTTP 客户端，业务请求可注入 T03 代理。Mac 竞态测试和两端静态检查通过。离线样本核对分页、请求头、重定向、账号错误、签名以及上传回执。真实账号、目录与传输闭环随 T06、T08、T10～T12 验收。

## T06 登录验证

两家登录入口各开独立临时 MyGo 会话。官方页面使用系统代理，业务账号校验走 Go 客户端。凭据只在校验后加密保存，取消窗口会终止当前校验。百度继续等待网盘 STOKEN，并在现有条件满足时提供粘贴 Cookie 入口。固定版本 MyGo 通过页面完成事件和一秒轮询取得 Cookie。

Mac 使用本地页面样本实际打开两家登录窗，验证 WKWebView 加载、重新加载、取消与 Escape。账号测试验证取消校验结果、凭据写入和删除失败、退出隔离及百度离线恢复。Go 竞态测试、MyGo vet 及两端编译通过。目录和传输收到明确的会话失效响应后显示重新登录，任务保留原账号并进入等待。竞态测试覆盖旧响应保护、网络错误保留会话和任务等待。真实账号扫码、百度 STOKEN 缺失时的服务端表现及 Windows WebView2 安装后的重试仍待验收。

## T08 目录验证

目录状态按账号和网盘独立维护。文件树通过 MyGo OutlineTable 展示，刷新保留有效列表，目录和账号变更取消过期读取。保存每家账号的目录路径及共享列宽。底层目录和树表测试覆盖排序、搜索、多选、父子去重、延迟结果及会话恢复。

Mac 使用隔离协议样本实际运行应用，展开目录、组合键选择父子项、按大小排序、中文搜索、双击进入目录、切到夸克再切回原路径均通过。竞态测试、MyGo vet 和 Mac／Windows 目标构建通过。

## T09 文件管理验证

新建返回准确远端对象后插入列表并聚焦名称。重命名和回收站按当前账号及原对象身份操作，确认框列出冻结的去重范围。Mac 运行验证覆盖右键新建、行内输入错误和修正、Esc 取消回收及确认回收。应用层测试另覆盖会话变化、同名和部分成功。竞态测试、MyGo vet、Mac 和 Windows 构建通过。真实网盘写入回归随 T18 验收。

## T10 与 T11 引擎验证

上传覆盖同名保留、目录和空文件、分片并发、已保存回执和实际内容回读。受控样本让回读失败后重试验证，检查不会重复提交已完成分片和合并。下载覆盖 Content-Range 和响应长度、断点恢复、链接刷新、跨域重定向凭据边界、已知摘要和无覆盖发布。Mac 使用目录句柄和独占重命名。Windows x64 已交叉编译，目标卷的发布行为待实机验证。

上传引擎在首次远端写入前持久化整批内容签名，队列可用它判断是否需暂停。离线用例覆盖相同内容、同大小异内容、空目录差异和拦截后无远端请求。

相同账号与目标目录的重复任务在远端写入前暂停，并保留原任务引用。Mac 隔离任务记录实际显示「查看原任务」与「仍然上传」，定位后选中原任务并显示详情。队列竞态测试覆盖并发判重、重启、明确继续及目录身份。上传明细可按原账号和准确对象打开云端目录，并定位原始或已重选的本地源文件。离线测试核对目录链、对象身份和账号变化。4.2.0 的旧版备份动作依赖替换快照，当前上传入口沿用同名保留两份。真实网盘回归随 T18 验收。

并发上传任务共享一个上传速率预算，设置调整会唤醒等待中的分片。竞态测试核对两个分片的总速率及关闭限速后及时恢复。

源文件重选沿用系统选择器，接受一个文件并在后台核对原任务指纹。竞态测试覆盖错误文件、失败任务恢复、保留手动暂停和账号切换；无窗口测试验证错误条目显示入口。真实系统面板与网盘闭环待实测。

取消后先等待执行者退出，再依据持久化意图判断是否待核对。夸克有准确文件身份时可查询远端结果并解除记录移除限制；百度及缺少准确身份的未决请求保留为待核对。离线测试覆盖重启、移除限制，以及核对期间不发送上传写请求。

## T14 设置验证

Mac 打开原生设置窗口并依次切换传输、网盘、网络和账号。测试核对默认值、并发限制、速率单位、失败后保留已提交设置、下载目录和代理凭据隔离。业务代理变更时，传输队列先等待活动任务保存检查点，再切换到最后一次保存的代理并恢复可运行任务，手动暂停保持。隔离竞态测试覆盖连续切换与恢复；真实网盘出口待端到端验收。官方登录页继续使用系统代理。Mac 安装包元数据版本为 5.0.0。竞态测试、MyGo vet 和两端目标构建通过。

## T13 队列与任务界面验证

应用层测试覆盖手动暂停重启保留、原账号等待、停止屏障、优先上传、失败项续传与任务回执顺序。Mac 使用隔离任务记录验证传输列表、共享计数、任务选择和 105 项详情翻页。账号变化和设置更新已连接到队列。移除记录会先归档明确的下载校验依据。选择同时删除下载文件时，按本地身份逐项移入系统废纸篓或回收站，保留共享目录和相邻文件；部分失败后保留记录并只重试待处理项。隔离测试覆盖归档失败、重启、同名替换和旧记录。Mac 系统废纸篓探针成功移动样本并保留相邻文件；完整界面和 Windows 实机仍待验收。工具栏对当前筛选范围暂停或继续，多选详情按所选任务的状态提供暂停、继续和移除记录。无窗口测试覆盖范围与可用动作；重复上传仍从单任务明确确认。竞态测试、MyGo vet 和两端构建通过。

上传入口从当前目录、目录行及系统菜单使用同一个冻结目标。Mac 隔离选择器返回本地样本后，应用成功写入正确账号与根目录的上传任务，并展示模拟服务失败。系统选择器混选已在 T03 验证，完整拖放及真实上传仍待验收。

## T11 下载入口验证

Mac 应用用隔离网盘样本从文件表选中「笔记.txt」，确认保存目录并创建下载任务。队列标记完成后，核对了目标目录的 1024 字节与受控服务内容完全一致。已通过竞态测试、MyGo vet 和两端目标构建。

下载文件数上限在所有批次间共享。同一批次可并发多个文件，仍按各网盘的单文件连接数工作。竞态测试覆盖并发上限、运行时调节及暂停后继续未完成项。

## T12 分享入口验证

Mac 用隔离剪贴板样本打开夸克分享，显示提取码和默认全选，提交后关闭面板并生成后台任务。样本限制到任务入队及失败反馈。普通任务记录未包含提取码或会话令牌。下载详情显示并复制标准分享链接；无窗口测试核对链接省略提取码，且仅为对应网盘展示。离线协议测试覆盖转存任务恢复、响应丢失后避免重复提交和准确清理。竞态测试、MyGo vet 与两端目标构建通过。

## T15 生命周期验证

Mac 验证构建关闭主窗后继续运行，再次启动只唤起原窗口。打开设置后从应用菜单退出，等待屏障完成并检查工作区记录。worker 测试覆盖系统休眠取消、检查点保存、唤醒后避免重叠和保留手动暂停。Mac 原生探针核对防闲置休眠声明的获取与释放，并用隔离剪贴板区分网址和普通文本。并发传输共享一个防闲置休眠声明。Mac 探针用 `pmset -g assertions` 验证两个活动、剩一个活动、全部结束时的声明数量分别为 1、1、0。应用处于前台时，包括设置和登录窗口，采用应用级活跃状态抑制完成通知。已核对接口并通过静态检查，多窗口通知交互待桌面验收。Windows 通知、托盘和休眠进入第二阶段。

## T16 安装包验证

在 Mac 运行 `Scripts/build-v5.sh` 生成 Apple Silicon DMG 与 Windows x64 NSIS 安装包，并写入和校验 SHA-256。DMG 完整性与应用签名通过，Windows 应用二进制确认为 x86-64。NSIS 检测 WebView2 Runtime，缺失时可打开微软下载页。在 Mac 只读挂载 DMG，核对 Applications 链接，将应用拷到隔离目录后再次核对签名、版本和最低系统声明。以隔离配置直接启动拷出的程序，确认进程持续运行并锁定预期数据目录。签名为临时签名，Finder 安装交互、macOS 14 与 Windows 安装运行仍待对应实机验收。

## T17 侧栏传输分类对照

按 4.2.0 基线补齐全部、进行中、已完成、失败四个分类的图标。Mac 深色验证构建实际渲染了四个图标，辅助功能树仍用现有业务文字标记各分类。网盘导航复用 4.2.0 的百度和夸克图标，Mac 深色截图核对图标置于名称左侧，辅助功能树各自保留一个网盘入口。工作区测试通过，浅色、输入法和其余页面对照继续验收。

Mac 实际窗口用图标按钮展开和收起侧栏及详情。辅助功能名称随状态显示「显示」或「隐藏」，宽度不足时仍保留工作区原有的详情收起规则。

未登录页恢复账号图标及图标式返回按钮，按钮仍通过「返回」提供辅助功能名称。MyGo 无窗口渲染在 960×640、640×400 的浅色和深色下核对账号提示及目录位置。此处未覆盖 Finder、VoiceOver 或系统输入法。

「查看全部」对齐到「传输」分组标题右侧。Mac 原生窗口截图与辅助功能树核对到独立可按、可聚焦的按钮，传输分类仍使用二级树条目。工作区导航竞态测试及两端静态检查通过。
