# Ferry Drive 5.0 测试用例

日期为 2026-11-10。全部用例待执行，依据 [产品方案](product-proposal.md)、[技术方案](architecture.md) 和 [任务清单](tasks.md)。本文件定义验收操作与结果，执行时逐个平台、网盘和子场景填写证据。

## 1. 环境和样本

### 分阶段测试环境

| 阶段 | 环境 | 用途 |
| --- | --- | --- |
| 第一阶段 | macOS 14，Apple Silicon | 最低 macOS 基线，全功能回归 |
| 第一阶段 | 当前开发机 macOS，Apple Silicon | 与当前 Swift 应用同机对照及资源记录；共享逻辑测试和 Windows 交叉编译／打包检查 |
| 第二阶段 | Windows 10 1809（17763），x64 | 暂定最低构建基线，全功能回归，覆盖 LTSC 2019 环境 |
| 第二阶段 | Windows 10 22H2，x64 | 常用 Windows 10 基线，全功能回归 |
| 第二阶段 | Windows 11，x64 | 同一个 Windows 安装包的全功能回归，记录实际系统构建号 |

第一阶段只在 Mac 上执行运行测试，涉及网盘的操作分别在百度、夸克执行。Windows 实际运行全部归入第二阶段，第一阶段在 Mac 上检查 Windows 编译和安装包生成。故障注入可由 Go 自动化测试承担，真实登录、传输、窗口交互及安装按对应阶段记录实际系统证据。

| 用例范围 | 第一阶段执行内容 | 第二阶段执行内容 |
| --- | --- | --- |
| C02～C05 | Windows 构建和打包证据单独记录，运行场景列为第二阶段待验证 | Windows 安装、运行时、登录前置及 DPI 全部子场景 |
| C01、C06～C69 | 执行 Mac 适用子场景与共享逻辑测试 | 执行其中 Windows 适用子场景，C06 为 Mac 专属 |
| 混合平台用例 | C01 的缺 WebView2、C40 的 Windows 名称／目录联接、C62 的资源管理器、C64 的 Windows 快捷键、C65 的 Narrator 等场景归第二阶段；执行相应 Mac 场景 | 在真实 Windows 环境补齐对应场景 |

C66 的“所有必测平台”按所属阶段解释，第一阶段以 Mac 双网盘闭环为完成条件。Windows 待验证不阻塞第一阶段收尾。第二阶段再核对最低 Windows 10 与其余 Windows 环境的完整结果。

样本包含三级目录、空目录、至少 120 个文件、中文／空格／长名称、同名文件、零字节文件、小文件，以及大于实际协商分片大小三倍的文件。记录分片大小、文件长度、源文件与回读结果的 SHA-256。目录样本逐文件比较摘要和相对路径。

每家网盘创建 `FerryDrive-V50-<唯一标识>` 专用目录，记录脱敏账号标识、远端对象 ID、下载目录与源文件清单。账号切换使用可控测试账号。代理、网络中断、磁盘错误与响应丢失优先在受控测试服务或隔离环境注入。

T01 固定当前基准的默认值、设置范围、快捷键、页面布局、关闭窗口行为和错误文案。历史测试中的旧上传确认页、独立行焦点选择等已替代行为，以当前源码为准。以下“基准”均指该固定结果。
