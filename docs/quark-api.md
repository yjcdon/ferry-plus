# 夸克接口实现与验证

QuarkKit 使用官方网页登录后保存在本应用钥匙串中的会话。文件、分享、转存及下载接口共用登录客户端，不建立第二套凭据存储。

## 已实现接口

| 能力 | 接口 | 行为 |
| --- | --- | --- |
| 账号目录 | drive-pc.quark.cn `/1/clouddrive/file/sort` | 完整分页；失败不返回部分列表；检查重复 fid 和返回的父目录身份 |
| 只读容量诊断 | drive-pc.quark.cn `/1/clouddrive/member` | 严格读取 total_capacity（总字节数）、use_capacity（已用字节数）；缺失或无效字段报错，不默认零；允许已用超过当前总容量 |
| 分享访问 | pan.quark.cn `/1/clouddrive/share/sharepage/token`、`detail` | 提取码及分享错误分类；文件令牌仅驻留当前会话 |
| 创建目录 | drive-pc.quark.cn `/1/clouddrive/file` | 返回服务器 fid；同名冲突不伪造新目录身份 |
| 提交转存 | drive-pc.quark.cn `/1/clouddrive/share/sharepage/save` | 立即返回 task_id，供调度器持久化 |
| 任务核对 | drive-pc.quark.cn `/1/clouddrive/task` | 独立查询，有界、可取消等待；取消本地等待不代表服务端撤销 |
| 下载地址 | drive.quark.cn `/1/clouddrive/file/download` | HTTPS 地址及所需请求头，Cookie 按域和路径选择 |
| 清理 | drive.quark.cn `/1/clouddrive/file/delete` | 仅接受明确 fid，禁止根目录；返回异步回执时等待确认后再成功返回 |

公共适配器负责将 fid 转换为远端引用；公共任务不保存 Cookie、stoken、文件分享令牌或下载直链。转存任务重启后可用已保存 task_id 查询，无须保存分享会话令牌。

分享根目录 `0` 是虚拟视图，根条目可以返回发布者的真实父目录；只有该视图放宽父目录校验，根批次转存仍传来源 `0`。账号目录与分享子目录继续严格核对父目录。查询参数中的 `+` 编码为 `%2B`，保留分享令牌原值。

业务码 `32003` 显示网盘空间不足，并提示在官方页面核对可用空间及空间权益。错误对象保留原始码与消息；用户提示不裸显服务端未替换的模板参数。2026-10-24 使用同一签名 App 和已存会话实际只读查询，总容量 10 GiB、已用约 25.6 GiB，确认本次账号已超额；这不是登录失效，也不妨碍已存文件下载。

API 的 HTTP 401 表示需要重新登录；403 保留为拒绝访问，不仅凭该状态撤销会话。403、404、已确认的业务码 32003 出现在下载地址解析阶段时立即失败，等待用户处理后手动重试；429 提示降低并发并保留有界退避。下载 CDN 的 403、404 仍可触发直链刷新，和解析接口的确定失败分别处理。

恢复分享文件令牌时，优先沿任务记录的相对目录逐层读取，只访问所选文件相关的路径，并在会话内缓存完整目录。只有缺少路径的旧记录使用可取消的目录扫描；会话释放后迟到响应不得重建缓存。

## 当前证据和边界

- 官方登录、凭据保存、独立进程恢复、账号与根目录鉴权已实际通过。
- 2026-10-24：正式适配器与任务／下载引擎链路完成夸克 148851 字节小文件下载，根目录返回 2 项；验证进程退出码为 0，输出本地 SHA-256。样例没有改写或清理网盘源文件。
- QuarkKit、FerryCore 构建通过；临时边界冒烟覆盖分享文案和提取码解析、外域拒绝、非法目录、根目录删除及轮询参数边界。
- 完整分享转存、分页、大文件续传、直链刷新和真实清理仍需复用登录状态执行。接口代码存在、构建通过不表示这些真实接口已验收。
- 两家账号已在新 App 菜单确认恢复。固定证书完成首次迁移授权后，签名摘要变化及源代码修改重建均可自动恢复登录，没有再次弹出钥匙串授权；继续 T-21 及 Computer Use 回归。
- 作者公开样例来自 [ComfyUI_GJJ_Nodes 模型下载说明](https://github.com/guojijun/ComfyUI_GJJ_Nodes#-模型下载)。仅选择根目录说明文件（69 字节）与深层 README（66546 字节），没有选择模型目录。真实转存根批次成功，深层批次已获取回执，但状态查询返回 `32003 / capacity limit[{0}]`；保留任务供后续核对，尚未完成这条分享任务的下载与清理验收。
- 对已有单文件失败任务执行界面重试后，只核对原回执并显示明确空间不足提示；前后转存回执记录的规范化 SHA-256 相同，没有新增任务或扩大清理范围。完整夸克分享验收需要账号恢复足够可用空间，程序不清理用户原文件来腾空间。

上游协议依据见 [架构设计第 8 节](architecture.md#8-夸克接口依据与待验证内容)。最终完成状态以 [任务清单](tasks.md) 和真实验证记录为准。
