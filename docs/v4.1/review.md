# Ferry Plus 4.1 方案 Review

日期：2026-10-29。审查范围：产品方案、技术方案、16 项任务、50 组测试用例及对应源码。

结论：本轮发现的 3 项方案缺口已修订，文档可作为实施依据。当前交付为设计，运行验收按任务和用例执行。

## 1. 审查方法

对照 `31077ec` 的 MainView、NetdiskFilesView、DirectoryBrowserState、FileTree、JobCoordinator 和 IntegrityManifest，检查状态归属、共享调用方、迁移清理及历史数据语义。独立审查后由主审复核源码并修订文档。

## 2. 发现与处理

| 问题 | 源码依据与影响 | 已完成修订 |
| --- | --- | --- |
| 原生列表迁移遗漏收起和搜索的选择规则 | NetdiskFilesView 收起时调用 discardDescendantSelection；DirectoryBrowserState 查询变化清理隐藏选择。遗漏会让隐藏子项进入批量操作 | 技术方案 5.1 明确收起清理独立子选、保留父选；搜索限定当前层并暂停展开。C13、C21 覆盖 |
| 历史依据归档与已验证状态表述混淆 | IntegrityManifest 只含路径、大小、算法、摘要；已验证记录由 JobCoordinator 精确对象规则生成 | 技术方案 5.4 区分参考依据与验证结论，C30 同步；保留现有格式 |
| 半屏适配遗漏固定窗口下限 | MainView 固定最小宽度为 820／960 点，部分屏幕半屏宽度小于此值 | 技术方案 5.2、T06 明确替换固定下限并联动侧栏／详情／工具栏／横向滚动；C01 记录实际尺寸 |

另修正源码表中的 TaskSearchField 定位，它位于 MainView.swift。

## 3. 交叉检查结论

- F-01—F-13 覆盖产品方案的窗口、导航、文件、传输、面板、设置、视觉、辅助功能和兼容要求，各有任务及用例。
- 应用自有界面实色要求贯穿四份方案；macOS 26 自动工具栏外观作为原型验收重点。
- FileTreeRow 继续服务分享选择页，WidthResizeHandle 继续服务详情栏；清理范围按调用方界定。
- 网盘、方向、搜索、分类共同决定可见任务；底部统计、全选和批量操作共用范围。
- 上传收尾文案归一，真实阶段与动作能力继续驱动执行；内容一致性检查沿用现有流程。
- 文档状态、任务状态和用例状态一致；本轮修改限于 docs。
