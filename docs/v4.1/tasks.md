# Ferry Plus 4.1 任务清单

日期：2026-10-29。当前进入实现与集成验收；逐项状态见[实施记录](implementation.md)，实际结果见[验收执行记录](test-execution.md)。

依据：[产品方案](product-proposal.md)、[技术方案](architecture.md)。验证编号来自[测试用例](test-cases.md)。

## 1. 顺序和完成口径

按基线 → 原型 → 文件工作区与窗口 → 传输与详情 → 面板和设置 → 集成验收推进。每项完成包含调用方迁移、对应验证和已替代实现清理。原型通过后再进入工作区替换。

| 任务 | 交付内容与完成标准 | 依赖 | 功能／用例 |
| --- | --- | --- | --- |
| T01 固定 4.0 基线 | 记录提交、构建方式、账号标识、任务与偏好快照、资源样本；准备独立测试目录和旧数据副本 | — | F-13；C46、C49 |
| T02 原生列表与实色窗口原型 | 验证异步树、继承选择、整列表头、列线拖动、右键、拖放、VoiceOver、半屏和 macOS 26 实色工具栏；记录实际 API 与尺寸参数 | T01 | F-01、03、04、11、12；C01、C08—C16、C42、C45 |
| T03 原生数据适配 | 建立稳定条目标识、节点观察、加载占位和重试；接入目录代次与会话；定位请求完成后消费 | T02 | F-03、04；C11—C15 |
| T04 选择与文件命令 | 迁移勾选、继承、焦点、右键范围、拖放、新建、重命名、回收站命令；原服务继续执行 | T03 | F-04；C13—C19 |
| T05 列与列表迁移收尾 | 原生排序、列宽保存、时间格式、水平滚动；切换 NetdiskFilesView；清理文件页手动表头，回归分享选择页 | T04 | F-03、13；C08—C12、C47、C50 |

| T08 统一任务行 | 从真实状态计算展示值，共用布局，承接阶段能力、部分失败及结果核对；核查列表高度补丁 | T06 | F-06；C23—C27 |
| T09 统一详情与历史清理 | 上传详情迁入右侧，承接重选文件／定位／核对；完成历史依据内部归档后清理旧手动入口 | T08 | F-07；C28—C31 |
| T10 统一业务面板 | 下载、上传、回收站列表与按钮布局；新建、重命名红框反馈；冻结上下文和文件访问交接保持正确 | T04、T07 | F-08；C32—C36 |

| T13 全局视觉与辅助功能 | 实色背景覆盖主窗口／详情／面板／设置，浅深色与对比度；键盘焦点、VoiceOver 全链路验收 | T07—T12 | F-11、12；C42—C45 |

## 2. 关键验收门槛

| 门槛 | 满足条件 | 后续动作 |
| --- | --- | --- |
| 原型可用 | T02 覆盖的交互实际可操作；macOS 14 可编译运行、26 自有区域实色；关键问题已修复 | 执行文件页迁移 |
| 替代完成 | 全部入口迁入新实现，共享调用方行为一致，对应 UI 用例通过 | 清理旧代码 |
| 历史数据兼容 | 登录、任务、偏好可读取；旧依据归档成功或原任务保留；真实状态准确 | 继续集成验收 |
| 功能完成 | C01—C50 中适用子场景全部有结果与证据，双网盘内容一致性通过 | 进入发布准备 |
| 资源可接受 | 同条件对比完成；明显增长已定位，交付差异有说明 | 随版本记录公布 |

## 3. 执行记录方式

实施时新增 `test-execution.md`，按 C 编号列出平台、构建、子场景、结果和证据。任务仅在所有对应验收项完成后标记完成。环境缺失写“待验证”，部分子场景完成写“部分完成”。4.0 的测试结果作为对比基线。

每项实施记录涉及文件、调用方迁移、验证结果及清理结果。资源分别记录基线和 4.1 数值。测试文件集中在独立样本目录，清理时核对对象清单，本地文件移动到废纸篓。
