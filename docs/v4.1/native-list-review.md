# 4.1 原生列表实现 Review 与修复

日期：2026-10-29。对应 T03—T05、T13、T14。源码范围：NetdiskOutlineView、DirectoryBrowserState、NetdiskFilesView。

## 已修复

| 发现 | 修复 |
| --- | --- |
| SwiftUI 重复 updateNSView 会反复建立尚未触发的 Observation 追踪 | updateInput 仅更新动作、能力和标记；业务变化由一次性追踪重建快照。转存标记变化只重绘，保持单条活动追踪 |
| 无障碍查询展开能力时 shouldExpandItem 带业务副作用 | shouldExpand／shouldCollapse 只返回权限；实际展开通知更新模型并加载，收起通知清理隐藏子选；程序恢复时沿用模型状态 |
| 重试按钮依赖 clickedRow，键盘／VoiceOver 激活时可能命中旧行 | 按钮直接弱引用对应节点，动作按节点启动加载 |
| 刷新时显示可接收拖放，随后上传上下文拦截而吞掉操作 | 原生目标校验读取当前上传能力；acceptDrop 返回业务回调的实际接收结果 |
| 换树刷新后普通行焦点丢失 | 目录状态保存对象引用和行位置，按引用恢复，消失后选择最近可见真实条目；导航或换账号清理 |
| 日期／大小直接使用 NSTextField，文字贴近行顶部 | 使用 NSTableCellView 包装并居中约束，和名称行对齐 |
| 空勾选框像禁用控件 | 使用清晰的 square／checkmark.square.fill 图标，保持 checkbox 辅助语义、选择状态和继承说明 |
| 名称列自动填充可能覆盖用户拖动宽度 | 原生表格采用 noColumnAutoresizing；仅实际视口宽度变化时由名称列承接差量，保持原生表头与边界拖动 |

## 资源与状态检查

- 观察及单元格回调弱引用协调器；拆除时取消加载任务、失效观察代次、清理缓存并解除代理。
- 快照递归仅深入已展开的加载子树，收起缓存的深层目录留待再次展开时访问。
- 程序展开恢复只重建可见状态，网络加载由实际用户展开或重试触发。
- 视口回调只在宽度实际变化时执行，列拖动沿用原生 header；新增视口偏好与旧列宽偏好共同恢复。
- 文件页空目录／搜索空结果使用 SwiftUI 投放区域；原生列表区域由 AppKit 单独管理拖放与表头事件，清理覆盖整个列表的重复投放包装及遗留 dropEntry 状态。
