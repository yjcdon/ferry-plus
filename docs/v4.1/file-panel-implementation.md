# 4.1 文件操作面板与反馈

日期：2026-10-29。对应 T10、T11 文件页部分；用例 C18、C19、C34—C39。

## 已实现

- 新建文件夹与重命名使用同一个实色名称输入面板，统一标题、输入、错误和按钮位置。
- 点击新建／确定时复用 `NetdiskRenameError.validationMessage`；错误红框就近提示，编辑时更新反馈，异步错误保留原输入。
- 新建、重命名、回收站操作保留打开面板时的账号、会话、目录和条目。提交前与异步结果返回后按原流程核对会话，变更时提供重新选择提示。
- 回收站确认按最长文件名自适应宽度，320 点起，最大 720 点并限制在当前屏幕可用宽度的 80% 内。清单随项目数量增高，内容区最小 80 点、最大 320 点，超过后滚动；较长名称中间省略并可悬停查看全文。
- 成功反馈按独立消息 ID 倒计时，最长 10 秒；错误与部分失败提示留在对应页面，支持关闭。更换提示、账号或离开页面时清理旧倒计时。
- 刷新期间保留可浏览列表，写入仍通过现有目录上下文控制；操作面板期间入口由同一页面状态管理。
- 新建、重命名成功名称采用【】引用；文件页工具栏组和独立搜索使用统一实色背景助手。搜索按页面实际可用宽度计算为 160—220 点，窄窗省去固定工具栏间隔。实际控件内距测量见[搜索尺寸记录](search-sizing-implementation.md)。
- 文件页可用宽度低于 520 点时，上传、下载与目录操作统一进入【操作】菜单，优先保留独立完整搜索；520—699 点保留上传、下载和目录操作菜单，700 点起沿用平铺按钮。上传与下载复用同一动作定义和启用条件。最窄窗口实际可见性由整合构建验收。
- 新建与重命名使用 `reveal(entry, select:)` 区分定位和勾选。新建选择新目录；重命名只按打开面板时的显式勾选状态迁移到准确新回执，未选项保持未选，父项继承选择沿用父项。百度改名后的新路径和夸克固定 fid 都使用回执引用定位，原其他选择继续恢复。
- 外部在网盘中显示的定位继续保留原自动选择语义；普通行焦点保持独立，刷新和定位合并为一次请求。

## 检查证据

- 下载确认由主窗口唯一入口展示，提交后直接调用原下载模型并关闭面板；清理唯一调用方始终为空的提交回调及专用初始化方法。上传确认继续保留清理待上传文件所需的回调。

- C38 源码复核：成功消息按独立 UUID 计时，新消息替换和手动关闭会取消旧计时，离页清空反馈；新建和改名收到远端回执后再次核对任务取消状态，使离页清理与回执完成保持同一生命周期。远端写入结果继续以实际目录刷新为准。
- 上传确认的初始项目和追加项目统一提示【请选择本地文件或文件夹。】，沿用本地 URL 筛选与去重规则；本次仅调整文案，差异检查通过。
- `swiftc -frontend -parse BaiduPCS-Swift/NetdiskFilesView.swift` 通过。
- `git diff --check` 通过。
- 焦点与勾选分离修复后，使用 SDK 26.5、Swift 6、macOS 14 目标对全部 App 源码静态类型检查通过；revealCreated 全部调用迁移到显式 select 参数。
- 已检查 DirectoryBrowserState.context：加载或读取失败期间写入上下文保持受控；目录与查询规则沿用原模型。
- 新建面板替代旧 alert 和局部 validFolderName，重命名共用输入布局。

## 运行验收

由主代理统一重建后执行双网盘非法名称、新建与改名成功／失败、删除部分失败、成功消息替换与计时、刷新期间浏览和账号切换。当前为静态已检查，运行待验证。

重命名选择补充：勾选 A/B 后右键未选 C 改名，保持 2 项；已勾选条目改名后按新引用保留原数量；父项已选时对子项改名继续继承父选。分别覆盖百度路径变化与夸克 fid 稳定场景。

## 任务移除确认补充

任务移除确认显式提供【取消】按钮并使用系统取消角色，Escape 沿用同一关闭行为。显示文案与其他业务面板统一使用中文，待执行任务集合在取消时清空。
