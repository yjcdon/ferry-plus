# 4.1 搜索输入与工具栏生命周期修复

日期：2026-10-29。关联 T07、T14，C21、C22、C44。

## 定位证据

实际 App 连续输入无匹配查询时，搜索会在过滤为零条后失去焦点，后续按键落到主窗口。临时诊断完整记录 56 条事件，只包含对象身份、文本长度和焦点状态。

- ⌘F 后，列表 FocusState 在输入前已经变为 false。
- 输入期间，旧搜索实例每次 update 前后原生值与绑定值的长度一致，编辑器保持首响应者。
- 过滤为空时，新 Coordinator 与搜索框先创建；新框尚未连接窗口，随后旧框结束编辑并销毁，首响应者变成主窗口。

证据指向搜索工具栏宿主随列表／空态切换而重建。

## 修复

传输工具栏挂到始终存在的主内容 HStack，由内部列表表达正常结果与空结果。文件搜索与传输搜索各使用明确的 ToolbarItem 标识。查询、输入绑定和现有原生焦点操作继续沿用。

临时 trace 源码与调用已清理，诊断源码文件移动到废纸篓。保留列表既有选择、键盘和删除命令行为。

验证：语法解析、差异空白检查及完整 App 源码快照的 Debug / macOS 14 目标类型检查通过。主代理重建后复验连续逐字输入、空／非空结果切换、继续输入、列表键盘与删除范围。
