- 实际日期文字贴行顶，改用原生单元格居中约束。
- 辅助功能查询会调用 shouldExpand，原副作用导致自动展开和元素索引失效；业务变更移到真实展开通知，重建后读取稳定。
- 重复 Observation 注册、刷新焦点和重试定位问题完成源码修复，继续覆盖交互。
- 上传详情分页逐条重读完整成员清单，改为每页一次；包测试覆盖归属和错误语义。
- 上传详情系统选源面板与主窗口展示占用打通，保留普通详情的常驻交互。
- 已加入传输提示补充 10 秒自动关闭；非活动侧栏文字改用系统颜色；系统自动侧栏玻璃按钮替换为实色入口。这三项在下一整合构建复验。
- Release 整合构建通过；半屏目录搜索和唯一侧栏入口已复验。原生列表空格勾选与 Return／⌘↑ 导航已实际操作。
- 目录浏览登录失效错误已接入现有会话处理，复用准确网盘实例；全 App 类型检查及相关账号测试 10 项通过。实际过期与恢复流程另行验证。
- 当前系统原生默认表头拖动复验出现事件问题。设置表头类并明确调用 AppKit 原生 mouseDown 跟踪后，两条列边界在 Release 构建均实际拖动成功。诊断日志与探针已清理。
- 用户截图指出搜索提示文字右侧裁切。实际工具栏原生控件在 110 点宽时文字区为 74 点，提示文字约 77.4 点；统一最小宽 160 点。窄窗将三个目录动作收进【操作】菜单，保留上传、下载和独立搜索；最终构建的半屏显示、⌘F、筛选、清空及菜单刷新已复验。诊断源码和窗口钩子已清理。
