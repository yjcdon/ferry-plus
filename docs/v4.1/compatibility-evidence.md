| 检查项 | 数量 |
| --- | ---: |
| 原始 Integrity 文件 | 18 |
| 当前仍存在 | 18 |
| SHA-256 与原基线相同 | 18 |
| 缺失 | 0 |
| SHA-256 变化 | 0 |
| 文件创建时间早于 4.1 实施日 | 18 |
| 当前可读取文件大小 | 18 |
| 基线保存原始大小字段 | 0 |

结果证明这 18 份原始记录的文件身份和内容摘要保持一致。基线格式只保存 SHA 字符串，单独的原始大小数值需原始文件副本补证。

## 持久化格式比较

| 范围 | `31077ec` 至检查版本的变化 | 兼容结论 |
| --- | --- | --- |
| Job、JobFile 与下载来源／阶段编码 | 仅 DownloadIntegrityDisposition 的文档注释调整，持久化字段、枚举与编解码函数相同 | 下载任务格式沿用 4.0 |
| UploadRecords 中上传任务、文件、会话、回执、完整性记录 | 源码相同 | 上传检查点格式沿用 4.0 |

| JobStore、IntegrityManifest | 源码相同 | 任务列表与摘要清单格式沿用 |
