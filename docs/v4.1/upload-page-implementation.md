# 4.1 上传详情分页读取优化

日期：2026-10-29。关联：T09、T14，C28、C50。

详情页显示最多 100 个文件，业务 API 允许单页最多 500 个。此前逐文件读取都会重新解码同一批次 manifest。详情随文件阶段更新时，单页会重复读取完整成员清单。

UploadStore 增加受控分页入口：先校验分页参数、批次 ID 与账号，读取一次权威 manifest，再按其成员顺序加载当前页文件。各文件继续校验文件 ID、任务 ID、账号及业务字段；页外暂存项保持独立。逐条读取前响应任务取消。

UploadCoordinator.files 委托该存储入口，返回格式及分页边界沿用既有约定。本次将每页 manifest 读取次数从页内文件数降为一次，内存仅保留该页文件。

验证：在既有 JobModelTests 中补充分页测试，覆盖旧快照、孤立暂存项、第一页／末页／空页、非法参数、账号不符、页外损坏隔离和页内损坏返回错误。执行 `bash Scripts/test-packages.sh --filter JobModelTests`，25 项全部通过。
