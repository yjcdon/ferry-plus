# Ferry Plus 4.1 测试用例清单

日期：2026-10-29。状态：集成验收进行中，逐项结果见[验收执行记录](test-execution.md)。依据：[产品方案](product-proposal.md)、[技术方案](architecture.md)、[任务清单](tasks.md)。

## 1. 环境、样本与证据

- 平台：Apple Silicon，macOS 14 最低支持版本与 macOS 26；浅色、深色、增加对比度；普通窗口、屏幕半宽、全屏。缺失平台记录待验证。
- 账号：复用本机百度、夸克登录。真实写入使用各自独立的 `FerryPlus-V41-<时间>` 样本目录，记录远端对象标识；验收记录展示脱敏账号标识。
- 文件树：至少三级目录、超过一屏的条目、中文和长名称、同名项目、缺少日期项目、不同大小文件。缺失字段等场景使用受控模型样本。
- 传输：零字节、小文件、多文件目录和分片样本。分片样本大于本次实际协商分片大小的三倍；记录实际大小和分片数。保留源文件与回读文件 SHA-256 作为内容比对证据。
- 状态：准备、排队、传输、暂停、合并、检查、发布、成功、跳过、取消、失败、部分失败。低概率状态通过已有测试或受控样本覆盖，真实双网盘链路另行执行。
- 旧数据：4.0 任务和偏好副本，包含历史 userProvided 依据、verified／pending／mismatch、上传失败及重选文件场景。执行前记录计数与稳定 ID。
- 证据：真实 App 截图／操作记录、相关日志、对象清单、摘要、编译与已有测试输出。凭据留在本机账号存储中。每行包含的子场景分别记录结果，全部满足后整行通过。
