# 4.1 统一传输行实施记录

对应任务：T08。日期：2026-10-29。

## 实现

- 上传、下载复用 TransferRowContent 的图标、标题、主操作、进度和状态布局。
- 全部网盘范围展示来源图标，单家范围由导航表达来源。任务行省去账号名称和完成／跳过计数，详情保留业务数据。
- 合并、内容检查和发布阶段统一显示“正在完成”，使用活动进度指示；真实 UploadPhase、内容检查和动作能力继续由原协调器管理。
- 上传行提供暂停、继续或重试主操作；重复任务继续支持定位原任务和继续上传，部分失败提供详情入口，核对远端结果继续使用既有菜单动作。
- 上传速度只在真实发送阶段展示。完成任务显示大小，详细路径、检查进度和估算信息由详情承接。
- List 行重建身份追踪改变结构的进度、重复关联、部分失败、移除进度、账号登录入口、提醒和错误；业务选择保持方向加 UUID 的稳定身份。

## 调用与样式简化

已核对 JobRow、UploadRow 和 TransferRowContent 的全部调用。任务行图标按钮样式统一由现有 TransferRowContent 提供；下载动作图标复用现有 TransferAction 映射，下载与上传各自的标题继续保留。UploadRow 的“仍然上传”复用 onAction(.resume)，清理重复回调。取消上传与优先上传共用相同的能力判断分支，执行仍分别路由至原动作。

## 验证

两份修改文件语法解析、差异空白检查通过。本次调用与样式简化已通过全部 App Swift 源码快照的 Debug 静态类型检查，目标为 macOS 14、Swift 6，使用现有 FerryKit 模块。实际窗口截图、动态行高和任务交互由集成构建后的 C23—C27 执行记录承接。
