# 4.1 统一传输行实施记录

对应任务：T08。日期：2026-10-29。

## 实现

- 上传、下载复用 TransferRowContent 的图标、标题、主操作、进度和状态布局。
- 全部网盘范围展示来源图标，单家范围由导航表达来源。任务行省去账号名称和完成／跳过计数，详情保留业务数据。
- 合并、内容检查和发布阶段统一显示“正在完成”，使用活动进度指示；真实 UploadPhase、内容检查和动作能力继续由原协调器管理。
- 上传行提供暂停、继续或重试主操作；重复任务继续支持定位原任务和继续上传，部分失败提供详情入口，核对远端结果继续使用既有菜单动作。
- 上传速度只在真实发送阶段展示。完成任务显示大小，详细路径、检查进度和估算信息由详情承接。
- List 行重建身份只追踪改变结构的进度、重复关联、部分失败和错误；业务选择保持方向加 UUID 的稳定身份。
