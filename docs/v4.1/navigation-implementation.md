# 4.1 窗口、导航与传输范围实施记录

对应任务：T06。日期：2026-10-29。

- 主窗口最小宽度从 820／960 点调整为 640 点，任务详情根据实际内容宽度自动收起；恢复空间时沿用用户展开和宽度偏好。
- 详情上限同时满足主窗口一半和主列表保留空间。窄窗显式打开详情会先收起侧栏，菜单与按钮使用同一展示绑定。
- 网盘范围使用浅色强调，当前页面继续使用完整选中背景，VoiceOver 提供当前传输范围含义。
- 底部统计直接读取 visibleItems，分类、搜索、网盘、方向、列表、统计和批量命令使用同一范围。
- 主窗口和侧栏应用不透明语义背景，侧栏内容背景交给实色表面。

静态检查：修改文件语法解析及差异空白检查通过；完整 App 源码快照按 macOS 14 目标类型检查通过。C01—C07 的实际窗口操作覆盖半屏、尺寸恢复、范围和批量操作，由整合验收记录承接。

## 路径按可用宽度展示

- 文件页先展示完整路径。实际宽度不足时，中间目录收入【上级目录】菜单，根目录和当前目录继续显示。
- 从任务定位百度目录时，按绝对路径读取真实祖先目录，保留每级目录的准确身份；再次进入父目录可继续上传、下载和目录操作。
- 既有定位记录在下次加载时补全祖先路径。

## 栏位分隔线

共享顶部、底部栏使用明确高度为 1 点的水平分隔线，避免 SwiftUI `Divider` 随容器布局方向绘制成竖线。影响范围为传输筛选栏、统计栏、任务详情底栏和侧栏底部。
